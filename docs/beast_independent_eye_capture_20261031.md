# Beast 눈별 관측 수집과 양안 검증 분리

> 2026-11-04: 이 문서는 수집 실험 기록이다. 현재 실행 순서는
> [사용자 확인형 통합 V1](beast_integrated_v1_20261104.md)을 우선한다.
> 눈별 수집 반복이나 DLT 적합을 통합본의 완료 조건으로 삼지 않는다.

## 목적과 범위

수동 원은 화면 좌표에 고정돼 있다. 왼눈 조절 후 고개가 움직이면 기존
왼눈 정렬은 현재 A에 맞지 않을 수 있다. 두 눈을 오래 같은 자세에서
조절하도록 요구하지 않고, 눈별 화면 좌표와 해당 순간 카메라 좌표를 수집한다.
최종 목표인 양안 겹침, 실물 깊이, 움직일 때 정합은 별도로 검증한다.

동일 자세의 양안 저장만 반복하는 방법 대신 기존 단안 저장 경로를 사용한다.
새 추적기·보정 모델·자동 활성화는 추가하지 않는다. 기존 pair_v2 시험도 유지한다.

## 이번 변경

- `DisplayObservationRecorder`: 기존 양안 저장의 안정성 검사를 모든 눈별
  저장에도 적용한다. 마지막 관측과 안정성 증거의 프레임이 같아야 한다.
- `DisplayCorrespondenceRules/Store`: 새 저장에는 setup_id와 안정성 증거가
  필요하다. 불충분한 증거는 파일 생성 전에 거절한다.
- `StereoAlignmentProbe`: LEFT/RIGHT SAMPLE, CAPTURE READY/HOLD STILL,
  MANUAL COMPARISON/BINOCULAR UNVERIFIED를 구분한다.
- `display_fit`: 안정성 증거가 있는 단안 파일도 증거를 검증한다.
  서로 다른 setup_id, 또는 착용 조건 미기록 자료와 기록 자료의 혼합을 막는다.
- 예전 단안 파일은 역사적 분석을 위해 읽을 수 있지만, 안정성을 소급 인정하거나
  두 파일을 같은 시점의 pair_v2로 바꾸지 않는다.

안정성 기준은 기존과 같다: 최근 0.6초, 서로 다른 3프레임 이상, 관측 간격
0.25초 이하, 시간 범위 180ms 이상, 카메라 기준 A 변화 2mm 이하.
이는 순간 움직임을 거르는 기준이며 2mm 정합 정확도 보장이 아니다.
최신성 150ms 제한, 인식 임계값, 카메라/작업대 프로필은 변경하지 않는다.

## 다음 실기기 절차

1. 착용 위치·도수 렌즈·Full SBS 1080p·0DoF·Extra Large·4.5m를 확인하고
   같은 착용 세트의 setup_id를 기록한다. 바뀌면 새 세트로 구분한다.
2. 기존 수집 서버와 수동 StereoAlignmentProbe를 사용한다.
   자동 후보 투영 옵션은 수집에 넣지 않는다. 사진·영상은 저장하지 않는다.
3. 왼눈으로 A 중심에 맞추고 CAPTURE READY일 때 Enter를 누른다.
   SAVED까지 잠깐 유지한다. 실패하면 현재 자세에서 이유를 확인한다.
4. 오른눈에서도 같은 순서로 저장한다. 두 저장 사이의 머리 위치는 달라도 된다.
   저장하는 동안 안경을 얼굴 위에서 밀거나 화면 설정을 변경하지 않는다.
5. 이 두 파일은 각각의 관측이다. 지금 3을 눌렀을 때 원이 갈라져도,
   다른 자세에서 맞춘 좌표를 단순히 동시에 표시한 것이므로 보정 실패 판정은 아니다.
   이 절차에서는 PAIR SAVED를 만들려고 두 눈을 다시 맞추지 않는다.
6. 먼저 눈별 한 번씩만 저장 경로를 확인한다. 이후 화면 위치·거리 분포를 확인해
   필요한 관측만 추가한다. 같은 위치의 반복 저장을 독립 관측 수로 세지 않는다.
7. 단안 manifest에는 원본 파일 경로·pose_id·fit/check를 명시한다.
   서로 다른 자세를 같은 pose_id로 묶지 않고, 동일 자세를 fit/check에 나누지 않는다.
   `--fit-pairs`는 pair_v2 전용이므로 이 자료에 사용하지 않는다.
8. 기존 DLT 경로로 눈별 후보를 계산하고 미사용 자세에서 오차를 확인한다.
   PD 보조 joint-fit 경로는 아직 pair 자료 전제이며 이번에 변경하지 않았다.
9. 통과 가능한 후보만 제한된 자동 SBS 시험으로 평가한다. 양쪽 원은 같은
   최신 3D A 위치를 각 눈의 투영으로 계산해야 한다. 한 원으로 편하게 보이는지,
   나사 깊이와 맞는지, 고개 이동 시 유지되는지를 각각 확인한다.

원본 자료를 많이 모으는 것만으로 자동 학습·정합이 일어나지는 않는다.
오차가 줄지 않으면 반복 수집을 멈추고 카메라 기하·착용 변화·시점 분포·모델을
구분해 조사한다. 화면상의 겹침만으로 광학적 초점 문제까지 해결되지는 않는다.
