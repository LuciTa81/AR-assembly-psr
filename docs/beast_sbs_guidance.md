# Beast 일반 SBS 안내 (R3)

2026-09-28. **합성 입력을 사용하는 소프트웨어 구현과 검사 결과다.**
실제 눈 보정, 나사 정합, 현장 추적 안정성이 완료됐다는 뜻은 아니다.
이번 실행에서는 카메라, Beast 출력, 외부 서버를 사용하지 않았다.

## 구현 범위

- Python의 선택적 `spatial` 계약을 일반 Unity 안내 화면에 연결했다.
  전체 논리 화면은 3840x1080, 각 눈은 1920x1080이다.
- 왼눈과 오른눈의 서로 다른 좌표에 원을 표시한다. IMGUI의 좌상단 원점을
  그대로 사용하며 오른눈 영역에만 1920px 오프셋을 적용한다.
- 기존 조립 상태 표시의 500ms와 별도로 위치는 150ms 미만에서만 표시한다.
  서버 pose age + 전체 요청 RTT + 수신 후 경과시간으로 보수적으로 판단한다.
- 같은 위치 관측을 반복 수신해도 좌표나 유효 시간이 갱신되지 않는다.
  유실/불일치/잘못된 응답 후에는 새로운 유효 관측이 필요하다.
- 세션, 카메라/작업대/표시 프로필, 해시, 목표 A-D, 눈별 크기를 검사한다.
  마커 유실, 만료, 연결 끊김, 화면 변경 때 원을 숨긴다.
- 화면 이름/크기/모드가 달라지면 자동 재정합하지 않고 재시작을 요구한다.
  실제 안내에 합성 프로필을 사용할 수 없도록 분리했다.

현재 `-SbsGuidance`만으로는 실제 위치 원이 켜지지 않는다.
검증된 실제 보정 프로필 로더가 아직 없으므로 `NOT CALIBRATED`가 정상이다.
기존 수동 SBS 조절/대응점 수집 모드는 별도로 유지했다.
S6는 사용자 최종 확인 대기이며 체결 토크를 보증하지 않는다.

## 카메라 없는 실행

저장소 루트에서 기존 프로젝트 Python 환경을 사용한다. 먼저 빌드한다.

```powershell
.\scripts\build_beast_unity.ps1
```

터미널 1에서 시험 서버를 실행한다. 설정 파일은 새 경로를 사용한다.

```powershell
python tests/unity/serve_spatial_fixture.py --config outputs/r3-demo/preview.json
```

설정 파일 생성 후 터미널 2에서:

```powershell
.\scripts\run_beast_unity.ps1 -SpatialPreviewConfig outputs/r3-demo/preview.json
```

노트북에 1536x432 SBS 시험 창이 뜬다. 순서는 A-D 이동, 마커 유실,
복구, 위치 동결/만료, 복구, 프로필 불일치, 누락 필드, 복구, S6, 연결 종료다.
기본 서버는 첫 요청부터 24초, 클라이언트는 화면 준비 후 29초로 제한된다.
첫 요청이 없어도 서버는 무기한 대기하지 않는다. Esc로 창을 종료할 수 있다.
이 시험은 영상 없이 메타데이터만 전송한다.

설정은 loopback 주소, 세션과 프로필을 고정하며 1~300초만 허용한다.
`-Beast`, 중앙 시험 원, 수동 보정 모드와 합성 시험의 혼합은 거절한다.
일반 입력 서버와 합성 시험 서버를 혼동하지 않도록 포트도 자동 분리한다.

Unity 자체 출력만 저장했으며 실제 카메라/데스크톱 사진은 저장하지 않았다.

```powershell
python tests/unity/check_sbs_capture.py outputs/unity_p1/r3-preview-final-1790527427461/frames
```

실제 창 검사를 통해 초기화 순서 문제를 수정했다. 위치 안내의 조회 간격은
기존 문구 표시보다 짧게 바꿨고, 150ms 만료 기준은 완화하지 않았다.
캡처를 포함한 실행에서는 간헐적으로 만료 숨김도 관측됐다.
따라서 이번 결과를 무깜빡임 또는 실제 지연 성능 보장으로 해석하지 않는다.
숨긴 창의 검은 캡처는 성공 증거에서 제외했다.

독립 검토에서 발견된 동일 ID 복구 문제도 수정했다. 바인딩이 일치하는
관측의 age/스키마/크기/사유/시각이 잘못돼 거절된 경우, 같은 ID의 필드만
고쳐 재전송해도 원을 다시 켜지 않는다. 6가지 재현 테스트의 실패를 먼저 확인한
뒤 수정했고, 실제 Unity JSON 파서에서도 누락 필드 재전송/새 관측 복구를 검사했다.
