# 관제와 시연 동선 정리

## 범위와 결정

기존 HTML/JavaScript, 확인 API, Unity와 단계 판정은 유지한다. 현재 작업과 행동,
보류 이유를 관제의 한 영역에 모으고 입력 수치는 접을 수 있게 한다.
새 웹 프레임워크·AWS·인식 모델·판정 임계값·정합 보정 변경은 하지 않는다.
자동 단계 건너뛰기나 재시작 API도 추가하지 않는다.

## 진행

- [x] 현재 관제와 확인 API, 실행 스크립트 확인.
- [x] 목표 기준 단계 이름, 한국어 행동, 확인 대기 상태를 테스트부터 보강.
- [x] 관제 배치와 전체 화면 보기, 입력 상세 접기 구현.
- [x] 기존 성공 옵션의 간단한 실행 경로와 시연 절차 작성.
- [x] 합성 입력 S0-S6 확인, PC/모바일·오류·영상 동의 검증.

## 완료 조건

상자·뚜껑·최종 확인에만 버튼이 있고 A-D에는 수동 건너뛰기가 없어야 한다.
오래된 입력·연결 끊김에서 확인과 작업 지시는 보류해야 한다. 진행 보존은 완료로
표시하지 않는다. 영상은 기본 꺼짐이며 명시적으로 켠 뒤에만 요청한다.
카메라 투영과 실제 안경 시야, 자동 접근·이탈 관측과 실제 체결 확인을 구분한다.
실기 실행은 별도 준비 확인 후에만 하며, 이번에는 카메라 없는 미리보기를 제공한다.

## 검증 결과

- Web 단위 검사 38개, 조립 세션·진행 보존 Python 검사 19개 통과.
- 실제 로컬 확인 API: 기존 수동 7회, hybrid 3회, 합성 리허설 3회 모두 최종 확인까지 통과.
- 1440/1280/390/320px 너비에서 8개 상태, 32개 스크린샷 검사 통과.
- 전체 화면 진입·종료·거절, 연결 끊김 시 확인 금지, 입력 상세 접기 확인.
- 영상 기본 꺼짐·명시적 켜기·프레임 지연 표시·끄기 뒤 늦은 응답 차단 검사 통과.
- 위치 추적 안내 16개 조합과 기존 S0-S6 합성 재생 회귀 검사 통과.
- 기본 런처는 사전 점검만 통과했으며 카메라·Unity·모델 추론은 실행하지 않음.
- 독립 리뷰의 조건부 이탈 안내·수동 나사 안내·접근성 알림 3건을 재현하고 수정.
  실제 스크린리더 낭독과 새 관제의 실기 동선은 아직 검증하지 않음.

기존 관제 사본은 `outputs/supervisor_usability/baseline-20261108/`에 보관했다.
화면 검사 결과는 `outputs/supervisor_usability/`에 있으며 합성 입력만 사용했다.
이번 작업은 카메라 설정·보정·Unity·판정 조건을 변경하지 않는다.
