# Supervisor Demo Candidate

## Approved Scope

Add a camera-first, operator-friendly supervisor page alongside the successful existing page. Keep calibration, Unity, perception, FSM, API, and the original supervisor unchanged. No camera or Unity execution during implementation.

## Experience

- Desktop: dominant workbench video, current action and target on the right, full sequence and recent meaningful changes below.
- Mobile: current action before video; no horizontal overflow.
- Current action, retained progress, recheck, and final operator confirmation remain distinct.
- A small labeled target diagram is schematic, never presented as registered camera or eye geometry.
- Video starts off. Synthetic input, recorded playback, and live camera remain explicitly identified.
- Operator confirmation remains limited by the existing session/revision and tracking checks.
- Recent changes are page-local, bounded, and cleared on a new session. They are not an audit log or completion evidence.

## Visual Direction

Neutral charcoal and off-white surfaces, restrained teal, amber, and blue state accents. No decorative charts, fabricated KPIs, nested cards, or autonomous workflow changes. Reuse existing Lucide fullscreen icons.

## Completion Criteria

Existing web tests pass; candidate browser tests cover stages, loss/recovery, confirmation, video opt-in, keyboard access, and desktop/mobile geometry. Screenshots inspected. Offline preview URL provided with synthetic labeling. Actual headset usability remains an explicit future check.
