- 저장: 25장, 모두 해시/해상도/전체 코너 재검출 통과. 중간 검출 실패 사진은 저장하지 않음.

## 추가 촬영 근거

총 1,350개 검출 코너의 범위는 x=252.98~1034.06, y=86.41~566.48 px입니다.
1280 x 720 화면을 3 x 3으로 나눈 코너 개수는 아래와 같습니다.

| 위치 | 왼쪽 | 가운데 | 오른쪽 |
| --- | ---: | ---: | ---: |
| 위 | 23 | 250 | 20 |
| 중간 | 58 | 902 | 44 |
| 아래 | 1 | 47 | 5 |

현재 후보의 초점 거리는 fx=824.32, fy=828.56 px이며
왜곡 계수는 [0.02759, 0.34889, 0.00122, -0.00253, -1.31265]입니다.
관측 코너의 최대 정규화 반경은 약 0.517입니다. 센서 모서리까지의 정규화
범위(~0.899)를 진단용으로 샘플링하면, 방사 방향 사상
`r_d = r * (1 + k1*r^2 + k2*r^4 + k3*r^6)`의 미분이
r~=0.747부터 음수가 됩니다. 이것은 관측 영역 밖으로 외삽한 보정식이 접히는
위험 신호이며 실제 렌즈가 이렇게 동작한다는 뜻은 아닙니다.

비교 실험으로 같은 20/5 분할에서 k3=0을 고정하면 학습/검증 RMS는
0.303018/0.348008 px이나 fx/fy가 789.44/797.80 px로 바뀝니다.
이 실험도 자동 채택하지 않았습니다. 낮은 RMS만으로 모델이 안정됐다고 볼 수
없으므로, 추가 관측으로 가장자리와 파라미터 안정성을 확인합니다.

현재 도구의 자동 경고는 중심 분포/면적/기울기만 검사하며 이 외삽 검사는
별도로 실행했습니다. 따라서 JSON의 빈 `warnings`가 최종 합격을 뜻하지 않습니다.

## 다음 촬영

기존 25장은 보존합니다. 같은 카메라/해상도/보정판으로 다음 15장을 추가합니다.

- 화면 위쪽 근처 3장, 아래쪽 근처 3장.
- 대각선 모서리 근처 3장.
- 전체 격자와 여백은 화면 안에 두고, 각 위치에서 기울기/거리를 조금씩 바꿉니다.
- 판을 크게 정중앙에 놓는 것만 반복하지 않습니다. 격자 코너가 바깥 영역에도 나타나야 합니다.

추가 촬영 후 두 세션의 장치/해상도/칸 크기 일치와 출처를 확인해 함께 평가합니다.
검증용 사진은 K/왜곡을 맞추는 데 사용하지 않습니다. 가장자리에서도 합격한
보정 후보를 확보하기 전 metric PnP/실제 표시 정합 완료로 진행하지 않습니다.

근거: [OpenCV 보정 문서](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)는
중앙에서 오차가 작더라도 비단조 왜곡 추정이 AR에서 문제를 일으킬 수 있음을 설명합니다.
