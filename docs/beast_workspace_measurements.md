나사구멍 간격 사용자 원문: "정사각형 형태야. 11cm".

초기 안내점 제안은 뚜껑면의 고정된 나사구멍 중심입니다. 높이 약 60 mm를
시험 시작값으로 두되 실제 구멍 주변 면 높이가 같은지는 작업대 검증에서 확인합니다.
이것은 조여지며 이동하는 나사머리 표면 추적이 아닙니다. 느슨한 머리의 65 mm를

아직 런타임 좌표/표시 설정은 변경하지 않았습니다.

다음 단계는 기준 마커와 상자 사이의 위치 및 방향을 확정하는 것입니다.

## 실측 마커 중심 등록

사용자 원문: "3에서 0은 28.5cm, 4는 20.5cm, 5는 41cm였어. 1, 2는 대각선으로 35cm, 50cm였어."
대각선 길이만으로 XY를 확정하지 않고 행열 정렬을 질문했습니다.
사용자가 "맞아, 두 줄·세 열로 정렬돼 있어"라고 확인하여 아래 값을 등록했습니다.

- ID 3 원점, X 오른쪽/Y 벽 쪽/Z 매트 위쪽. 단위 mm.
- ID 0=(0,285,0), 1=(205,285,0), 2=(410,285,0).
- ID 3=(0,0,0), 4=(205,0,0), 5=(410,0,0).
- 파일: `configs/beast_workspace_metric_20260927.json`. 기존 ROI용 픽셀 설정과 별개입니다.
- 사용자 근삿값과 정렬 확인에 기반하며, 정밀 계측한 24개 모서리 좌표는 아닙니다.

2차 원본 3장에 적용한 pose 재투영 RMS는 2.201/2.579/2.074 px였습니다.
이는 카메라 기준 마커 적합 오차이며, 나사 위치/눈 정합 완료가 아닙니다.

사용자 원문: "나사마다 높이달랐어. 구별할수있나..? 꽉조이는게 좋을까".
따라서 기존 사진에는 나사머리 높이 60/65 mm를 일괄 적용하지 않습니다.
나사 높이를 맞춘 뒤 머리 윗면 높이를 직접 확인하고 새 사진으로 등록합니다.
도구와 상세 결과: [작업대 위치 등록](beast_workspace_registration.md).

추가 설명 원문: "6cm지 조였을때는. 근데 돌출된건 거의 없고, 다 조인 상태나 다름없긴해. 꽉 조이지 않았을뿐이지".
이 설명을 반영하여 초기 클릭 평면과 안내점 높이를 모두 약 60 mm로 사용합니다.
불필요하게 더 세게 조이도록 요구하지 않습니다. 작은 돌출 차이는 미측정 오차로
남아 있으므로 기존 기준 사진의 클릭 결과는 후보일 뿐이며 다른 자세에서 검증해야 합니다.
앞의 새 촬영 요구는 높이 차이가 큰 것으로 해석했을 때의 안내 이력입니다.

사용자가 기준 사진 02에서 A/B/C/D를 클릭하고 Enter로 확정했습니다.
후보 `beast-workspace-centers-20260927-v1-targets-20260927T113302Z-ce42c89c`를
로컬에 보존했습니다. XY는 카메라 보정/마커 pose/클릭 및 높이 가정으로 계산한
후보이며 직접 자로 잰 나사 XY 값이 아닙니다. 실제 눈 정합은 아직 하지 않았습니다.
