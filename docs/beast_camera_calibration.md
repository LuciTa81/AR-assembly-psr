# Beast 카메라 보정 (P2a)

이 도구는 렌즈의 내부 파라미터 후보를 계산합니다. 안경의 원을 실제 나사에
맞추는 착용자 보정이나 나사 위치 추적을 완료하는 도구는 아닙니다.
기존 인식/Unity 실행 설정에 결과를 자동 적용하지 않습니다.

## 준비

- A4 가로, 실제 크기 100%, 흑백 단면으로 보정판을 출력합니다.
- 가로/세로 100 mm 눈금을 자로 확인하고 평평한 판에 붙입니다.
- 접힘, 휘어짐, 반사 코팅, 무늬 위의 테이프를 피합니다.
- 출력한 판은 10 x 7칸, 내부 코너 9 x 6개, 한 칸 25 mm입니다.
- 양축 출력 배율이 다르면 재출력합니다. 같은 비율로 달라졌다면 실제 한 칸
  길이를 측정해 `--square-mm`로 입력합니다.
- 카메라를 사용하는 다른 앱/실시간 인식 서버는 종료합니다.

## 촬영

프로젝트 루트에서 P0에 구성한 Python으로 실행합니다.

```powershell
& "$env:LOCALAPPDATA\ARAssembly\beast-mvp\.venv\Scripts\python.exe" -X utf8 -B -m server.realtime.camera_calibration capture --camera-index 1 --backend dshow --width 1280 --height 720 --square-mm 25
```

카메라 index는 고정된 장치 ID가 아닙니다. 미리보기가 Beast 시점인지 확인하세요.

1. 노트북 촬영 창을 클릭한 뒤 영문 입력 상태에서 `C`를 누릅니다.
2. 보정판 전체와 흰 여백이 보이게 하고 멈춘 상태에서 `Space`를 누릅니다.
3. 저장 장수가 증가하는지 확인합니다. 전체 코너를 못 찾으면 저장하지 않습니다.
4. 중앙/좌우/위아래 위치, 기울기, 가까운/먼 거리를 바꿔 25장을 모읍니다.
   같은 자세에서 연타하지 않습니다. 머리나 판을 움직인 뒤 멈추고 저장합니다.
5. 25장이 되면 자동 종료합니다. 중간 종료는 `Q` 또는 `Esc`입니다.

원본은 자르거나 줄이지 않은 1280 x 720 PNG입니다. 저장 전에는 화면에만
미리보기하며, `Space`를 누른 사진만 기록합니다. 창을 닫거나 15분이 지나도
카메라를 해제합니다. 해상도가 요청과 다르면 중단하고 명시적으로 재설정합니다.

사진/manifest는 기본적으로 `%LOCALAPPDATA%\ARAssembly\beast-mvp\camera_calibration`
아래 새 세션에 저장합니다. Git 저장소가 OneDrive 안에 있으므로 해당 저장소의
`outputs`를 실사진 기본 경로로 사용하지 않습니다. 외부 API/클라우드 전송은 없습니다.
Codex의 Windows 앱 가상화 환경에서는 실제 위치가 아래로 연결될 수 있습니다.

```text
%LOCALAPPDATA%\Packages\OpenAI.Codex_2p2nqsd0c76g0\LocalCache\Local\ARAssembly\beast-mvp\camera_calibration
```

## 계산

촬영 종료 후 로그에 나온 세션 디렉터리를 지정합니다.

```powershell
& "$env:LOCALAPPDATA\ARAssembly\beast-mvp\.venv\Scripts\python.exe" -X utf8 -B -m server.realtime.camera_calibration solve --session "<촬영 세션 절대 경로>"
```

최소 15장의 유효한 서로 다른 사진이 필요합니다. 다섯 번째마다 검증용으로
제외하고 나머지로 K/왜곡 계수를 계산합니다. 검증 사진에서는 K/왜곡을 고정하고
자세만 추정합니다. 따라서 검증 RMS도 절대 거리 오차나 착용 정합 오차는 아닙니다.

결과는 새 `candidate-*.json`, 분석 내역은 `analysis-*.json`입니다.
사진 해시/해상도/코너 검출 실패는 원인과 함께 기록합니다. 충분한 사진이 없거나
수치가 잘못되면 후보 파일을 만들지 않습니다. 낮은 RMS만으로 합격시키지 말고
사진 선명도, 위치/기울기/거리 분포, 보지 않은 실제 지점도 확인해야 합니다.

1. 실제 카메라 보정 후보를 검토하고 필요한 사진을 다시 촬영합니다.
2. 마커와 나사 A-D의 실제 위치/높이를 측정하고 PnP를 검증합니다.
3. 0DoF/기본 2D의 고정 표시 설정에서 착용자별 정합을 진행합니다.
4. 정합하지 않은 점, 고개 이동, 재착용, 추적 유실에서 표시를 검사합니다.
