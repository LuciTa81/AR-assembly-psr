- 이후 읽기 전용 EnumDisplaySettingsExW의 ENUM_CURRENT_SETTINGS와 지원 모드 목록에서
  DISPLAY2의 현재 출력 및 지원 모드를 3840x1080@60Hz로 확인했다.
- 실제 Unity도 VITURE Beast 3840x1080을 감지했고 같은 해상도의 FullScreenWindow로 실행했다.
- 노트북은 2880x1800이다. SBS 3840은 두 눈의 1920 너비를 나란히 보내는 한 화면이다.

## 착용자 피드백과 화면 설정

사용자 보고: 멀리서 보면 괜찮으나 가까이 가면 원이 두 개로 보이고,
나사보다 깊숙이 들어가 보였다. 이는 광학 정합 통과가 아니며,
관측 데이터 만료로 인한 깜빡임과 별도로 근거리 양안 정합/깊이 문제를 조사한다.
이 피드백만으로 화면 거리, 눈별 투영, 착용 위치 중 하나를 원인으로 단정하지 않는다.

사용자는 화면 설정을 Extra Large, 4.5m였던 것으로 기억한다고 했다.
확정된 현재 OSD 값이나 과거 보정 당시의 증빙으로 취급하지 않는다.
현재 후보 JSON에는 OSD screen size/distance 값이 없고 자동 조회하지 않는다.
실제 메뉴 값은 변경 없이 확인해 다음 검사 조건으로 기록해야 한다.

현재 fit 보고서는 눈마다 fit_count=6, check_count=0,
status=needs_check_points, calibration_valid=false다.
별도 자세/거리의 검증점이 없는 최소 점수 후보이므로 근거리 일반화를 보증하지 않는다.
우선 실제 작업 거리에서 한 눈씩 정합을 확인하고 양안 깊이/편안함을 확인한다.
필요한 경우에만 보정점을 보완하며, OSD 설정을 바꾸면 기존 눈별 보정을 재검증한다.

공식 안내의 Screen Size는 가상 화면의 지각 크기, Screen Distance는
눈에서 가상 화면이 떨어져 보이는 거리(1~5.5m, 0.5m 간격) 설정이다.
실제 나사 거리를 넣어 자동 정합시키는 기능으로 설명하지 않는다.
Full SBS에서 각 설정이 현재 투영에 주는 정확한 영향은 아직 실측하지 않았다.
