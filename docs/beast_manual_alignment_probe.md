# Beast 수동 단일점 정합 검사

2026-09-27. 사용자가 수동 검사 모드 추가/시험에 동의했습니다.

## 목적과 경계

자동 보정 전에 현재 0DoF/2D 표시에서 원 하나가 실제 나사 A와 어떻게 겹쳐
보이는지 확인합니다. 방향키로 옮기는 **수동 광학 검사**이며, 카메라 추적,
YOLO, 조립 상태 판정, camera-to-eye 보정 또는 양안 정합 완료가 아닙니다.
서버/네트워크 요청과 카메라 캡처를 실행하지 않습니다.

수동 원 위치는 `manual_single_point_optical_probe` 기록입니다.
`calibration_valid=false`, `display_alignment_verified=false`를 유지하며 기존
카메라/나사 후보나 Unity 자동 안내에 적용하지 않습니다. 같은 자세/깊이에서
원 한 개가 맞아도 이동, 거리 변화, 다른 목표의 정확도를 보장하지 않습니다.

## 실행과 조작

프로젝트 루트에서:

```powershell
.\scripts\run_beast_unity.ps1 -Beast -AlignmentProbe -ProbeSeconds 180
```

- Beast의 0DoF/Default 2D, 착용 위치, 화면 크기/거리 설정을 유지합니다.
- 나사 A는 먼 왼쪽입니다. 노트북과 상자 위치를 바꾸지 않고 자세를 유지합니다.
- Unity 창에 키보드 포커스가 있어야 합니다. 필요하면 Alt+Tab으로 Beast Assembly Guide를 선택합니다.
- 방향키: 네이티브 표시 좌표 2 px 이동. Shift+방향키: 20 px 이동.
- R: 중앙으로 초기화. Enter: 해당 화면 위치 기록. Q/Esc: 종료.
- 기본 180초 후 종료하며 기간은 1~300초입니다. 해상도/출력 디스플레이가 바뀌면
  원을 숨기고 종료합니다. 조작이나 Enter로 제한 시간을 연장하지 않습니다.
- 실제 물체에 맞는지는 착용자가 확인합니다. 앱은 일치 여부를 판정하지 않습니다.

먼저 양안으로 십자 중심을 나사 A에 맞춥니다. 그 뒤 자세와 원 위치를 유지한 채
왼눈/오른눈으로 번갈아 보며 어긋남과 복시 여부를 확인합니다. 원과 실제 물체를
동시에 편하게 보기 어렵다면 중단하고 그 결과를 기록합니다.

정규화 좌표, 해상도, 기록 순서, 로컬 monotonic 시각만 저장합니다.
카메라 관측과 연결된 대응점이 아니므로 이 파일로 보정 행렬을 만들지 않습니다.
이 모드 자체는 사진/영상을 촬영하지 않습니다.
표시 이름/시작/종료는 Player log에 남습니다. 파일 쓰기 실패는 오류 종료합니다.
commit/push 및 서버 배포를 수행하지 않습니다.

## 구현과 검사

- `ManualAlignmentState.cs`: 옵션, 이동/경계, 만료, 명시적인 미보정 기록.
- `GuidancePresenter.cs`: 선택된 모드의 원/십자/키 조작과 로컬 기록.
- `GuidanceReceiver.cs`: 해당 모드에서 HTTP polling을 시작하지 않음.
- `DisplayBootstrap.cs`: 출력 준비 완료 후에만 수동 표시 시작.
- `GuidanceCaptureProbe.cs`: opt-in 렌더 검사에서 수동 시작/준비 상태 캡처.
- 기존 조립 상태 필터/YOLO/카메라 설정은 변경하지 않음.

## SBS 수동 시험 (후속 구현)

카메라/HTTP/상태 추론 없이 눈별 원의 위치만 조절합니다.
별도 SDK, 드라이버, 펌웨어 설치 또는 자동 하드웨어 설정 변경은 하지 않습니다.
사용자가 Beast에서 Full SBS 3D와 0DoF를 선택하며, Windows에서는 확장 출력을
사용합니다. 화면 크기/거리와 착용 위치는 시험 중 바꾸지 않습니다.

```powershell
.\scripts\run_beast_unity.ps1 -Beast -StereoAlignmentProbe -ProbeSeconds 180
```

표시 이름이 VITURE Beast이고 전체 화면 3840x1080 또는 3840x1200일 때만 시작합니다.
해상도만으로 SBS와 UltraWide를 구분할 수 없으므로 실제 눈별 전달 확인이 필수입니다.
0DoF/3D/화면 크기/거리는 SDK로 읽지 않으며 사용자의 확인입니다.

1. 처음에는 왼쪽 영상에 L/초록 원, 오른쪽 영상에 R/하늘색 원을 표시합니다.
   오른눈을 감았을 때 L만, 왼눈을 감았을 때 R만 보여야 합니다.
   반대로 보이거나 둘 다 보이면 진행하지 않고 결과를 알려줍니다.
2. 전달이 맞으면 Space를 눌러 사용자가 확인한 것으로 기록합니다.
   왼눈 정합 화면으로 바뀌고 반대쪽 영상은 검게 비웁니다.
3. 고개와 안경을 고정한 채 오른눈을 감고 방향키로 왼눈 원을 나사 A에 맞춘 후 Enter.
4. 2를 눌러 오른눈 정합으로 전환합니다. 왼눈을 감고 같은 나사 A에 맞춘 후 Enter.
5. 3을 누르면 양쪽에 각각 맞춘 초록 원을 표시합니다. 두 눈을 뜨고 겹침/편안함을
   확인하고 Enter로 좌표 쌍을 기록합니다. 실제 성공 여부는 별도로 사용자에게 묻습니다.

- 1/2/3: 왼눈/오른눈/양안 비교. 양안 비교에서는 방향키가 원을 움직이지 않습니다.
- 방향키 2 px, Shift+방향키 20 px. 각 눈의 1920 px 너비 안에서만 이동합니다.
- R: 선택한 눈만 중앙으로 초기화. C: 좌우 전달 확인으로 돌아가 확인/표시 기록을 무효화.
- Enter: 현재 좌표 기록. 양안 기록은 두 눈을 각각 기록한 후에만 가능합니다.
  원을 다시 이동/초기화하면 그 눈의 이전 확인 기록을 무효화합니다.
  쓰기에 성공한 경우에만 하단에 SAVED가 1.5초간 표시됩니다.
- Q/Esc 종료. 기본 180초, 최대 300초이며 조작해도 연장되지 않습니다.
- 표시 이름/해상도/전체 화면 모드가 바뀌거나 시간이 만료되면 표시를 숨기고 종료합니다.
- 렌더 버퍼뿐 아니라 실제 출력 디스플레이 크기도 검사합니다. 렌더 버퍼가 3840으로
  남아 있어도 실제 출력이 1920으로 바뀌면 표시/기록을 차단하며 재실행이 필요합니다.
- 키가 안 먹으면 Alt+Tab으로 Beast Assembly Guide에 포커스를 둡니다.
- 눈이 불편하거나 겹치지 않으면 억지로 맞추지 않고 중단합니다.

로컬 저장: `%LOCALAPPDATA%/ARAssembly/beast-mvp/display_probe/stereo-<unique>/point-NNN.json`.
좌우 값은 **각 눈 영상의 왼쪽 위 원점** 기준이며 오른눈 x에 전체 화면의 1920 px
오프셋을 더한 값이 아닙니다. 파일에는 표시 크기, 채널 확인 여부, 선택 화면,
양쪽 기록 여부, 좌표와 monotonic 시각을 저장합니다.
`calibration_valid=false`, `display_alignment_verified=false`를 유지합니다.
카메라 pose/관측과 연결되지 않으며 자동 안내에 적용하지 않습니다.
