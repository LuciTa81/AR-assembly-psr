본 폴더는 프로젝트 진행 중 수행한
- 저장 테스트
- replay 테스트
- validation 테스트
- 장시간 안정성 테스트
- warp/ROI 테스트
- classifier/PEBF 실험
의 기록을 저장한다.

## 파일명 규칙

예:
- `2026-03-31_session_pipeline_check.md`
- `2026-04-01_long_recording_test.md`
