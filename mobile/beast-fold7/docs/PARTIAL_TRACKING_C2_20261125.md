# 부분 마커 추적 C2 후보

## 상태

- 2026-11-25: 별도 후보 APK 제작, 빌드 및 오프라인 검증 완료.
- 폰 개발 연결 없음. 설치, Android 네이티브 수치 시험, 실제 착용 검증은 미실시.
- v1을 교체하거나 성공 판정한 상태가 아님. 서버/웹 변경, 카메라 실행, 새 촬영 없음.
- 기존 성공본 보관 파일 5개의 SHA256 및 크기 일치 확인. C1 APK도 그대로 유지.

## 변경 범위

`PartialReferenceBank`는 C1의 단일 기준 화면을 보완한다.

1. 유효한 5개 이상 마커 관측에서만 기준 화면 생성.
2. 최소 500ms 간격, 최대 6개, 원래 촬영 시점부터 30초 유효.
3. 현재 C1 계산이 성공하면 그 결과를 그대로 반환.
4. C1 실패 시에만 과거 기준 화면으로 각각 재계산.
5. 두 결과의 A~D 위치가 모두 카메라 2.5px 및 카메라 좌표 2.5mm 이내로 일치할 때 추가 표시 후보를 반환.
6. 검출된 실제 마커 수는 그대로 보고. 추정한 중심을 검출 마커로 세지 않음.
7. 작업 재시작, 시간 역행/중복 시 초기화. 부분 관측으로 기준 만료 시간을 연장하지 않음.

불확실한 프레임은 계속 숨긴다. 이전 화면 위치를 고정해 표시하는 기능은 없다.
두 기준 결과의 일치는 독립적인 정답 검증이 아니며, 공통 오차가 남을 수 있다.
기준 화면은 시간순 최근 6개이며, 시점 다양성을 최적화한 선택 방식은 아직 아니다.
3개만 보이는 상태에서 초기화하거나 30초 이상 부분 관측만으로 무제한 유지하는 기능도 아니다.

기존 카메라/작업대/A~D/눈별 보정, 205/205mm 등록값, 단계 타이밍은 변경하지 않았다.
단, C1부터 사용한 APRILTAG 모서리 정밀화 때문에 v1과 화면 위치가 완전히 동일하다고 주장할 수는 없다.

## 가림 재현 결과

저장된 영상/사진의 마커 관측에서 오른쪽 또는 왼쪽 두 마커를 계산 입력에서 제외했다.
기준 화면은 가림 이전 관측만 사용하고, 가림 이후 숨겨진 관측은 비교에만 사용했다.
각 기준 시점 이후 최대 30초를 비교했다. 아래 건수는 서로 겹치는 재현 사례이며 독립된 촬영 횟수가 아니다.

| 자료 / 가림 | 비교 사례 | C1 표시 판정 | C2 표시 판정 | 추가 표시 중 5px 및 5mm 기준 내 |
| --- | ---: | ---: | ---: | ---: |
| 성공 영상 / 오른쪽 2,5 가림 | 3263 | 1227 | 2075 | 844 / 848 |
| 성공 영상 / 왼쪽 0,4 가림 | 3263 | 1091 | 1758 | 667 / 667 |
| 별도 촬영 / 오른쪽 2,5 가림 | 66 | 19 | 31 | 12 / 12 |
| 별도 촬영 / 왼쪽 0,4 가림 | 66 | 11 | 12 | 1 / 1 |

- 비교한 사례에서 기존 C1 성공 결과를 잃은 경우는 0건.
- 오른쪽 추가 표시 중 4건은 5mm 기준 초과. 최대 6.82mm. 카메라 화면 차이는 최대 3.72px.
- 왼쪽 전체 결과에는 C1에서 이어받은 5mm 초과 3건이 남아 있음. 최대 7.64mm.
- 기준은 같은 프레임의 정밀 5마커 계산값이다. 실제 물체 위치를 별도 계측한 절대 정확도가 아니다.
- 입력 관측을 제외한 시험이지 실제 손/도구로 픽셀을 가린 시험은 아니다.
- 별도 촬영의 왼쪽 유지율은 여전히 낮다. 좌우 모두 안정적으로 된다는 결론은 보류.
- 원자료: `pose-comparison/continuity-bank-full-report.json`.
- 간격 5개로 먼저 표본 검사한 결과: `pose-comparison/continuity-bank-report.json`.

## 짧은 누락 연결 실험: APK 미포함

`FlowBridge`는 저장 영상의 마커 내부 특징점을 OpenCV pyramidal LK로 추적한다.
현재 이미지 움직임으로 재투영하고, 최대 500ms까지만 허용한다. 특징점 왕복 검사,
세 마커 이상 지지, RANSAC, 마커 그룹 제외 시 외삽 변화, 현재 검출과 일치를 검사한다.
추적 성공만으로 시작 시각을 갱신하지 않는다.

- 저장 영상 1034프레임을 분석. 자연 검출 실패에서 추가 계산 8프레임, 이 구간의 정답은 없음.
- 두 프레임씩 검출을 제거한 비교 가능 180건 중 97건 계산 반환, 96건 비교 기준 이내.
- 1건은 카메라 최대 6.81px, 좌표 5.68mm, 눈별 투영 15.89px 차이.
- 따라서 C2에는 포함하지 않았다. 실패 원인과 실제 가림/장면 전환 검증 후 별도 후보로 판단한다.
- 원자료: `pose-comparison/continuity-flow-report.json`.
- 구현 근거: https://docs.opencv.org/4.13.0/d4/dee/tutorial_optical_flow.html
