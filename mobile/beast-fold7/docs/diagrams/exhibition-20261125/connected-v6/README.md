# 연결형 통합 설계도 v6

2026-11-26. 기존 v3/v4/v5 결과물은 그대로 유지했습니다. 앱·서버·보정 코드는 변경하지 않았습니다.

## 변경

- 분리된 렌더링 확대 패널을 제거하고 R1~R6를 실제 주 경로에 배치했습니다.
- 카메라 → ArUco/PnP → A–D 좌표 → 입력 확인 → 좌우 투영 → 유효성 검사 → Canvas → 레이어 합성 → Presentation → Beast를 연결했습니다.
- 작업 상태에서 Canvas 색상·문구 및 Three.js 부품 선택으로 분기합니다.
- 카메라 인코딩·상태 전송과 EC2·웹·S3 경로도 같은 도면에서 연결합니다.
- Python·Unity 등 개발 이력은 실시간 호출이 아닌 별도 영역입니다.

## 검사

- 설계 주 경로 31개 노드가 하나의 연결 그래프를 이루는지 검사했습니다.
- 화살표 간 교차 및 박스 관통 0건.
- 155개 박스 내부 텍스트의 넘침 및 화살표와 글자 겹침 0건.
- 전체 렌더 이미지 시각 확인.

## 해석 범위

MediaPipe·HMM 경로는 현재 APK에 없는 통합 설계입니다. 동작이 검증된 기능으로 오해하지 않도록 도면에 명시했습니다. 시간 증거 게이트, R1~R6 등은 코드의 책임·데이터 흐름을 설명하기 위한 논리적 모듈 구분이며 각각의 별도 프로세스나 직렬 함수 호출을 뜻하지 않습니다.

VITURE, ONNX Runtime, AWS 등 아이콘 출처와 렌더 코드 대조는 이전 `render-detailed-v5/SOURCES.md` 및 상위 `icons/sources.json`, `icons/official-render-sources.json`에 기록되어 있습니다.
