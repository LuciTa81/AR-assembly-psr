# 혼자 실행하기

## 준비

1. Fold7에 Beast를 USB-C로 연결한다. 노트북과 무선 디버깅 연결은 일반 실행에 필요하지 않다.
2. Beast를 Full SBS, 0DoF, Extra Large, 4.5m으로 맞춘다. 출력은 3840×1080이어야 한다.
3. 보정할 때의 착용 위치와 상자·마커 배치를 유지한다. 205·205mm 등록값과 기존 보정은 변경하지 않았다.
4. 폰에서 **AR Assembly**를 연다. 앱을 여는 것만으로 카메라가 켜지지는 않는다.

## 시작과 종료

- 연결과 인식 준비가 끝나면 **작업 시작**이 활성화된다. 비활성 상태에서는 화면의 연결 상태를 확인하고 새로고침 모양의 **연결 확인** 버튼을 누른다.
- 작업 시작을 누르고, 카메라 또는 USB 사용 권한이 나오면 허용한다.
- 상자 → 뚜껑 → 나사 A~D → 최종 검사 순서로 진행한다.
- **작업 종료**는 안내와 카메라만 끈다. 앱은 닫히지 않는다.
- **다시 시작**을 누르면 이어하기가 아니라 상자 배치부터 새 작업을 시작한다.
- 홈으로 나가거나 다른 앱으로 이동하여 이 앱이 비활성화되면 안내를 종료한다. 돌아와도 카메라는 자동으로 켜지지 않는다.
- USB 또는 외부 화면 연결이 끊기거나 Full SBS가 해제되면 실행을 멈춘다. 재연결 후 출력 설정을 확인하고 다시 시작한다.

## 그대로 유지한 조건

- 상자 7초, 뚜껑 6초는 유효한 추적 시간 기준이며 실제 배치·닫힘을 자동 판별하지 않는다.
- 근접 증거 0.8초 누적 이후 파란 안내 대기 4초. 초록으로 바뀌려면 유효한 근접 관측이 필요하므로 체감 시간은 더 길 수 있다.
- 초록 안내가 실제로 표시된 뒤 3초 후 다음 나사로 넘어간다. 토크나 체결 품질의 자동 검증은 아니다.
- 최종 검사 안내 10초 후 종료, 전체 실행은 기존처럼 최대 5분이다.
- 시작 후 카메라 프레임이 15초 동안 전혀 없으면 실행을 종료하고 USB/권한 확인을 안내한다.
- 일반 실행에서 사진·영상·음성은 저장하지 않는다. 진단용 숫자 로그는 남는다.
- 추적 숫자는 **진단 정보**에서 펼쳐 볼 수 있다.

## 보관본과 현재 후보

- v1 동결본: `baseline/v1-frozen-20261121/v1.apk` 및 동일 폴더의 소스·검증 자료.
- 단독 실행 수용본: `baseline/standalone-accepted-20261122/accepted.apk`, 버전 `1.1-candidate`.
- 현재 상태 관제 후보: 버전 `1.2-observer`. v1과 별도로 검증한다.
- 버전 코드가 낮은 v1 APK를 되돌려 설치할 때는 개발용 APK 다운그레이드 옵션(`adb install -r -d`)이 필요할 수 있다. 서명이 다르다는 이유로 앱을 삭제하지 않는다.
- 영상 전송·녹화, 화면을 끈 상태의 백그라운드 실행은 아직 지원하지 않는다.

## 노트북에서 상태 보기

1. 폰과 노트북을 신뢰하는 같은 Wi-Fi에 연결한다. VPN·게스트 네트워크·기기 격리가 있으면 연결되지 않을 수 있다.
2. 앱의 **관제 연결**을 켜고 상태 공유를 확인한다. 이것만으로 카메라는 켜지지 않는다.
3. 옆의 **관제 주소** 아이콘을 눌러 주소를 복사하고 노트북 브라우저에서 연다. `#key=` 뒤의 임시 연결 키까지 포함해야 한다.
4. 폰에서 작업을 시작하면 웹의 현재 작업·다음 행동·추적 상태가 갱신된다. 작업 기록은 기본적으로 단계 전환만 표시한다. 전체 변화를 선택하면 안내·추적 변화도 볼 수 있다.
5. 관제 연결을 꺼도 폰 작업은 계속된다. 앱을 벗어나거나 Wi-Fi가 바뀌면 공유가 닫힌다. 다시 켜면 새 연결 주소를 사용해야 한다.

이 버전은 상태 조회 전용이다. 원격 시작·종료·단계 넘김, 영상 전송·저장은 없다. 작업 기록은 접속 중인 브라우저 메모리의 최근 240개 변화이며, 새 작업 또는 새로고침 시 초기화된다. 전체 실행 로그를 영구 저장하는 기능은 아니다.

HTTP 상태 통신은 암호화되지 않는다. 공용 Wi-Fi, 포트 포워딩 또는 외부 공개는 사용하지 않는다. 연결 키는 공유를 켤 때마다 바뀌며, 브라우저 주소창에서 읽은 후 제거된다.
