# 관제 화면 고도화 · 2026-11-25

## 적용 범위

- 상단 메뉴: 실시간 관제 / 작업 기록 / 저장 영상 / 기기·설정.
- 작업 기록은 서버에서 최근에 시작한 작업 하나를 선택한 후 최대 240개를 조회한다.
- 최근 50개 작업을 선택할 수 있다. 과거 이벤트는 삭제하지 않는다.
- 실행 이력이 없는 앱 대기 세션과 종료 후 재연결 대기 이벤트는 화면에서 제외한다. 실제 종료와 작업 중 수신 공백은 유지한다.
- 새 작업의 상태가 수신되면 최근 작업으로 돌아간다. 새로고침/서버 재시작 뒤에도 DB 기준으로 최근 작업을 찾는다.
- 저장 영상은 별도 메뉴에서 촬영일 필터, 길이·용량, 저장 상태, 삭제 예정, 다운로드·삭제를 제공한다.
- 스크롤바는 1.5초 비활동 후 투명해진다. 오른쪽 가장자리 접근/스크롤로 다시 표시되며 키보드 탐색과 고대비 환경에서는 접근성을 우선한다. 스크롤 자체를 차단하지 않는다.
- 로그인 화면은 중앙 GitHub 로그인 패널과 조립 도면 배경으로 변경했다.
- 배경은 기존 box-outline.json의 참고 외형 치수로 만든 정적 PNG다. 실시간 상태/안경 투영 결과가 아니다.
- SafeOps의 LoginScreen.tsx 구조와 globals.css 스타일을 참고했다. 회사 로고, 행사장 지도, 로그인 API를 복사하지 않았다.

## 변경하지 않은 것

Android 앱, A~D 보정, 단계 판정, 녹화 동의, 공개 가입 설정, 보관 기간, S3 객체, NOVA.
실제 촬영과 녹화는 켜지 않았다. 서버 RECORDING_ENABLED=false, MULTI_USER=false 유지.

## 검증

- 서버 전체 테스트 122개 통과. 최신/선택 작업, 240개 제한 이전 필터링, 소유자 격리, 종료 후 대기 재전송 회귀 테스트 포함.
- Next.js 프로덕션 빌드, 서버 TypeScript 검사 통과.
- Playwright: 1920/1440/820/390/320px에서 영상 on/off 위치 유지, 가로 넘침 없음, 실제 WebCodecs 합성 프레임 디코딩, 로그인 배경 로드, 로그인 오류, 작업 선택, 독립 영상 메뉴, 스크롤바 숨김/복귀, 다운로드·삭제 mock 검증.
- 운영 Chrome: GitHub 로그인 성공. 최근 작업 11개 표시, 이전 작업 선택 시 해당 작업 4개 표시, 저장 영상 2개 별도 조회 확인. 영상 전송/녹화는 시작하지 않았다.
- 운영 서버 읽기 전용 smoke: 소유 기기 1개의 최신/선택 작업 격리 통과.
- 화면 자료: `.local/recording-ui/`. UI 자동화의 상태·영상은 테스트 데이터이며 운영 촬영물이 아니다.
