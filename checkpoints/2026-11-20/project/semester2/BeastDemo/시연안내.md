# Beast 시연

현재 실행은 로컬 시제품입니다. 사진/영상 저장과 외부 전송은 하지 않습니다.

## 1. 단계 안내 + 크롬 영상

Beast: 일반 2D + 0DoF. Windows: 확장.
PowerShell에서:

```powershell
& 'C:\Users\fresh\Downloads\BeastDemo\Start-Beast-Demo.ps1' -Mode Live -CameraIndex 0
```

크롬에서 http://127.0.0.1:8765/supervisor.html 을 열고 `영상 표시`를 켭니다.
카메라 번호는 재연결 시 바뀔 수 있으니 안경 움직임과 영상이 일치하는지 먼저 확인합니다.
마커 0개만으로 카메라가 틀렸다고 단정하지 않습니다. 렌즈 가림/시선도 확인합니다.

종료: 서버를 실행한 PowerShell에서 Ctrl+C. 안경 앱도 닫힙니다.

## 2. SBS A 원 후보 시험

1번 서버와 안경 앱을 종료한 뒤, Full SBS 3D + 0DoF로 바꿉니다.
상자/마커 위치와 안경 크기/거리 설정을 유지합니다.

```powershell
& 'C:\Users\fresh\Downloads\BeastDemo\Start-Beast-Demo.ps1' -Mode Sbs -CameraIndex 0
```

Beast 앱에 키보드 초점을 두고 Space로 시작합니다. Q로 종료할 수 있고 최대 30초입니다.
노트북에는 카메라 좌표의 A-D 진단 미리보기가, 안경에는 A 원 후보가 나옵니다.
이 모드에서는 조립 상태 대시보드가 연결 끊김으로 바뀝니다. 두 모드는 아직 통합 전입니다.
일반 SBS 안내 모드의 `Display calibration required`는 오류가 아니라 미보정 공간 안내 차단입니다.
따라서 오늘은 2D 상태 안내와 별도의 SBS 후보 원 시험으로 구분합니다.
마커/pose 유실 시 원을 숨기며, 현재 심한 깜빡임과 깊이/정합 오차가 남아 있습니다.
미보정 사용자에게 맞는다고 설명하지 않습니다.

스크립트는 종료 후 카메라 세션이 정리될 때까지 잠시 기다립니다.
다른 카메라 프로그램을 동시에 실행하지 마세요.

## 교수님께 설명

"1학기의 오프라인 인식 파이프라인을 실시간 입력으로 확장했습니다.
Python 서버의 상태 결과를 Unity 안경 안내와 관제 웹이 함께 받습니다.
Unity에서는 디스플레이 출력, 단계별 문구, 유실 처리, 양안 SBS 표시와 눈별 보정 도구를 구현했습니다.
나사 A에 자동으로 원을 표시하는 공간 정합 후보 시험까지 진행했고,
현재는 추적 유실/깜빡임을 줄이고 보정에 쓰지 않은 자세에서 정확도를 검증하는 단계입니다."

오프라인 session17의 94.12%는 현재 실시간 정확도가 아닙니다.
도구 접근/이탈 관측은 체결 토크 보증이 아닙니다.
다음 단계: A 원 안정화 -> 독립 자세 검증 -> A-D 선/목표 화살표 -> 상태 안내 통합 -> 여러 세션 평가.
