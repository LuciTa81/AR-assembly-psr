## 검출 표시본 해석

표시본은 촬영 후 **각 JPEG에 동일 모델을 다시 실행한 오프라인 진단**이다. 당시 실시간 비동기 YOLO 출력이나 상태 전이 결과로 해석하면 안 된다. 청록색은 물체 검출, 마커 테두리와 ID는 해당 사진에서 검출된 마커다. 정합이 유효하지 않아 A–D 분석 위치와 추정 끝점은 표시하지 않았다.

사진 재분석에서는 실제 드라이버를 잡는 경우가 있었지만 배경·손 등을 driver/handle로 잘못 검출하는 경우도 확인됐다. 마지막 사진에는 driver가 2개 검출됐다. 검출 점수는 모델 점수이며 실제 체결 완료 확률이 아니다.

이번 사진만으로 실제 나사와 기존 A–D 분석 위치의 정합, 접근 후 이탈 전이의 성공 여부는 확인하지 못했다. 저장된 사진에 A–D 원이 없는 이유는 정합이 무효이기 때문이지, 해당 기능을 삭제했기 때문이 아니다.
