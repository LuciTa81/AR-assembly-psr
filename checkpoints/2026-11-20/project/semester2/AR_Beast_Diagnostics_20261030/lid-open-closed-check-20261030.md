# 뚜껑 열림·닫힘 비교

2026-10-30. 카메라 진단과 저장 사진 비교만 수행했다. Unity, 실시간 단계 판정,
템플릿, 임계값, 카메라·눈별 보정은 변경하지 않았다. 카메라는 종료했다.

## 수집
- 열린 상태: 사용자 준비 확인 후 실제 관측 약 9.68초, 98프레임.
- 닫힌 상태: 사용자 준비 확인 후 실제 관측 약 9.77초, 99프레임.
- 각 실행은 시작 대기 포함 13초 제한이며 종료 정리까지 약 15초였다.
- 상태별 실제 저장 원본 1장, 실시간 분석 이미지 1장, 오프라인 재분석 이미지 1장.
  각 3장, 두 상태 합계 6장이다. 다른 프레임의 영상은 보존하지 않았다.
- 두 수집은 camera 0 / SUBPIX / 동일한 카메라·작업대 프로필이다.
- 실시간 추적 통과는 열림 40/98, 닫힘 77/99. 두 실행의 stale 이벤트는 0회.
  이 수치는 뚜껑 분류 정확도나 정합 정확도가 아니다.
- 원본과 분석 기록은 새 capture-08-lid-open, capture-09-lid-closed 폴더에 복사했다.
  원본 증거 파일 6개와 오프라인 결과 2개씩 SHA256 일치를 확인했다.
- 외부 전송, Unity 실행, 추가 카메라 재촬영은 하지 않았다.

## 같은 방식의 오프라인 비교
열린 상태의 저장 프레임 38은 실시간 SUBPIX에서 재투영 오차로 거절됐다.
같은 원본에 APRILTAG 모서리 정밀화를 적용하면 RMS 1.823px로 통과한다.
닫힌 상태의 저장 프레임 39도 같은 APRILTAG로 재분석했고 RMS 1.901px다.
이는 ArUco 마커를 바꾼 것이 아니며, 실시간 검출 설정도 바꾸지 않았다.

두 사진 모두 같은 높이 60mm의 lid_surface 영역을 64x64로 추출할 수 있었다.
카메라·작업대 프로필 해시는 같고 원본 해시는 JSON에 기록했다.
실제 상태는 사용자 준비와 사진 검토로 붙인 라벨이며 자동 분류 결과가 아니다.

## 판단
- 투명 뚜껑 때문에 중앙 영역에는 열린 상태와 닫힌 상태 모두 상자 내부가 보인다.
- 두 사진의 추정 카메라 위치 차이는 65.57mm다. 이는 추적 모델의 추정값이며
  사람의 이동량을 독립 실측한 값은 아니다. 시점 변화 자체는 허용되는 사용 동작이다.
- 높이 60mm 면으로 정규화해도 그 아래에 보이는 상자 내부는 시점에 따라 달라진다.
  따라서 두 사진 차이를 뚜껑 유무에 의한 차이로만 해석할 수 없다.
- 기존 grayscale/edge 특징 거리의 두 사진 간 값은 0.17419다. 확률, 임계값,
  성능 또는 인식 성공률이 아니며 상태 내 변동과 비교하지 못한 참고값이다.
- 상태별 원본이 1장뿐이다. 같은 사진을 기준으로 삼고 다시 평가하는 방식으로
  인식 성공을 주장하지 않는다. 이번 자료만으로 S1 -> S2 자동 전이를 활성화하지 않는다.

## 다음 최소 작업
새 촬영 전에 저장 원본에서 뚜껑 가장자리와 상자 테두리의 차이를 검토한다.
중앙 영역 단독보다 테두리 근거를 함께 사용하는 후보가 필요한지 먼저 확인한다.
후보가 정해진 뒤 별도의 열린/닫힌 관측에서 확인하고, 기존 상태 필터에 연결한다.
작업대 추적 유실과 뚜껑 분류는 별개의 문제로 기록한다.
