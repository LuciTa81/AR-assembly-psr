## 사진

- 원본 8장과 비교 이미지 8장, 총 16장입니다. 사용자 요청한 최대 20장 이내입니다.

## 해석

새 ROI는 기존 후보와 같은 18mm 나사 영역, 뚜껑 중앙 80%, 높이 60mm를 사용합니다.
카메라·작업대 프로필 해시와 ROI metric 좌표가 저장 사진 후보와 일치합니다.
이번 검출은 빠른 기본 SUBPIX입니다. 노출과 150ms 제한은 변경하지 않았습니다.

정상 사진에서는 ROI가 나사 주변과 뚜껑 중앙을 따라갑니다. 실패 사진에는 마커가
화면 안에 있어도 움직임 방향으로 번진 모습이 확인됩니다. 저장되지 않은 모든
거절을 번짐으로 단정하지 않습니다. 95/199는 진단 통과 수이며 정합 정확도가 아닙니다.
이전 실험과 자세·움직임이 같지 않아 시간 초과 0회를 일반적인 안정화 완료로 보지 않습니다.

이번에는 나사 체결·뚜껑 상태를 판정하지 않았습니다. 다음은 준비 확인 후 편한 정지
자세에서 뚜껑 열림/닫힘 자료를 비교하는 단계입니다. 기존 템플릿은 자동으로 재사용하지 않습니다.
