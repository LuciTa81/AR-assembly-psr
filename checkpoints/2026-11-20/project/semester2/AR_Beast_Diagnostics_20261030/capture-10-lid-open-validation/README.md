# 열린 상태 원본 10장 검증

2026-10-30. 사용자 준비 확인 후 새 열린 상태를 촬영했다.
원본 10장과 같은 프레임의 실시간 분석 이미지 10장을 저장했다.
validation의 두 비교 그림은 이 원본에서 만든 파생 이미지다. 추가 촬영은 아니다.
촬영·기록 프로세스는 정상 종료했고 외부 전송·Unity 실행은 하지 않았다.

## 촬영 기준
앞으로 이런 촬영 검사의 기본 요청은 원본 최대 10장, 약 1초 간격으로 한다.
분석 이미지는 원본 장수와 별도로 센다. 같은 세션의 10장은 독립 실험 10회가 아니다.
프레임을 받지 못하거나 저장에 실패하면 숫자를 채우려 재촬영하지 않고 실제 저장 수를 보고한다.

실행 옵션은 --camera 0 --duration 15 --save-every-seconds 1 --max-samples 10
--roi-candidate --corner-refinement subpix였다.
기존 진단 도구에 max_samples / --max-samples를 추가했다. 허용 범위 1~12,
기존 기본 12는 유지하며 이번·후속 요청에서 10을 명시한다.
원본과 대응 preview를 묶어 하나의 sample로 센다. 자동·수동 저장 모두 상한을 지킨다.
미리보기 저장 상한 외의 인식 정책·시간 제한·보정값은 바꾸지 않았다.
기능 전 테스트 7개 실패를 확인했고 구현 후 관련 테스트 69개가 통과했다.
테스트 결과: ../lid-rim-offline-01/sample-limit-tests.xml.

## 비교 조건
- 기존 열린 기준 1장과 닫힌 기준 1장을 고정했다.
- 오른쪽 BD, 뒤쪽 AB의 폭 12mm 및 끝부분 제외 15%를 그대로 사용했다.
- 사진별 재정렬, 기준 사진 교체, 임계값 튜닝, 새 모델 학습은 하지 않았다.
- 모든 10장을 APRILTAG 모서리 정밀화로 오프라인 분석했다.
- 실시간 SUBPIX 추적 기록: 121프레임 중 tracking 88, pose_rejected 33, stale 0.
  추적 비율은 뚜껑 판정 정확도가 아니다.
- 카메라·작업대 프로필 해시와 기준 사진 해시가 이전 분석과 일치한다.
- 원본 10장의 한눈보기로 열린 상태를 확인했다. 흐린 프레임은 정밀 판독에 한계가 있다.

분석 가능 프레임 21, 31, 41, 51, 61, 71, 91에서 오른쪽 영역은 모두 닫힌 기준에 더 가깝다.
마지막 91에서는 뒤쪽도 닫힘 쪽이다. 두 영역의 단순 합의로 전이시켰다면 문제가 되는 반례다.
실제 단계 판정에는 연결하지 않았으므로 이번 검사에서 S1 -> S2 전이를 실행한 것은 아니다.

## 원인 조사와 결정
오른쪽 띠의 기존 특징을 밝기 정규화 영상과 edge 성분으로 나눠 비교했다.
7장 모두 두 성분에서 닫힌 기준과의 거리가 더 작았다.
정규화를 없앤 단순 흑백 차이도 7장 중 6장에서 같은 방향이었다.
따라서 가중치 하나나 정규화만 바꾸면 해결된다는 근거는 없다.
촬영 시점, 경계 위치, 투명 표면, 흐림의 영향을 아직 분리하지 못했다.

이 자료는 기존 후보 비교 방식의 반례이며, 후보를 바로 실시간에 연결하지 않는다.
새 자료에 맞춰 임계값을 낮추거나 오른쪽 영역을 제거해 성공으로 보고하지 않는다.
이번에는 추가 촬영을 멈추고 원본을 보존한다.
다음 최소 작업은 저장된 반례에서 실제 뚜껑 경계와 분석 띠가 어디를 보는지 검토하고,
기준 한 장과의 픽셀 유사도보다 안정적인 근거가 있는지 확인하는 것이다.
새 방식을 만들면 이번 10장은 개발 자료가 되므로, 다시 별도의 검증 자료가 필요하다.
