2026-10-30. 추가 촬영 없이 기존 저장 사진만 사용했다.
카메라 API 호출은 금지한 상태로 실행했다. 원본, 카메라·작업대 프로필,
실시간 설정, 템플릿, 임계값, Unity 코드는 변경하지 않았다.

- 높이 60mm에서 기존 중앙 영역과 네 나사 중심 연결선 주위의 폭 12mm 띠를 비교했다.
  양 끝 15%를 제외했다. 모든 변에 같은 규칙을 적용하고 사진별로 위치를 맞추지 않았다.
- 띠는 실제 뚜껑 외곽을 독립 측정한 것이 아니라 등록 나사 중심에 기초한 후보다.
  현재 투영 폭은 약 12~23px다. 비교 그림의 확대가 원본 세부 정보를 늘리지는 않는다.

두 사진의 추정 카메라 위치 차이 약 65.6mm와 투명 표면, 반사, 흐림도 혼재한다.

## 기존 닫힌 사진 3장으로 보조 확인
새 기준 사진을 그대로 재평가하지 않고 이전에 저장한 다른 세 프레임을 사용했다.
고정된 동일 띠와 특징 거리로 현재 열림·닫힘 기준에 대한 거리를 각각 계산했다.

- 뒤쪽 AB: 닫힘 기준과 0.112~0.134, 열림 기준과 0.218~0.243.
- 오른쪽 BD: 닫힘 기준과 0.113~0.142, 열림 기준과 0.239~0.248.
- 이 세 사진에서는 두 후보 모두 닫힘 기준에 더 가까웠다.
- 중앙 및 나머지 변도 같은 방향이므로 테두리의 우월성을 검증한 실험은 아니다.
- 연속 세션의 닫힌 사진만 사용했다. 독립적인 열린 검증 사진이 없으므로
  열린 상자를 닫혔다고 판단하는 오검출이나 전체 정확도는 평가하지 못했다.
- 보조 사진에는 내부 나사가 있어 중앙 영역의 내용물 영향도 남는다.

## 결정
오른쪽 BD와 뒤쪽 AB를 중앙과 함께 검토할 보조 ROI 후보로 남긴다.
앞쪽 띠의 큰 거리만 보고 자동 전이 기준을 만들지 않는다.
새 모델 학습, 합산 가중치, 임계값 조정, S1 -> S2 자동 전이 활성화는 하지 않는다.

다음 최소 검증은 다른 열린 관측에서도 닫힘으로 오판하지 않는지 확인하는 것이다.
머리 위치를 영구 고정시키는 것이 목표가 아니라, 편한 범위의 시점 변화에서도
판단이 유지되는지 검증해야 한다. 이 검증 전에는 후보를 실시간 경로에 연결하지 않는다.

## 산출물과 검증
- results/comparison.png: 중앙과 네 띠의 열림/닫힘 비교.
- results/open-regions.png, closed-regions.png: 실제 원본 위 후보 영역.
- results/analysis.json: 사진·프로필 해시, 자세, ROI 좌표, 특징 거리.
- closed-history.json: 보조 확인 사진 3장의 원본 해시와 모든 거리.
- analyze_lid_rim.py, check_closed_history.py: 계산 재현 스크립트.
- roi-helper-tests.xml: 기존 ROI 투영·무효 관측·원본 보존 테스트 20개 통과.
- 분석 스크립트에서 띠 폭 12mm, 길이 70%, 높이, 안쪽 방향을 assertion으로 확인했다.
  모든 분석 영역은 유효했고, 카메라 API를 금지한 상태로 계산을 완료했다.
- 원본 5장 및 프로필의 불변성은 해시로 확인한다. 새 이미지는 저장 원본의 파생 비교 그림이다.

프로젝트 루트에서 PYTHONPATH를 프로젝트 루트로 설정하고 로컬 Python 환경으로
스크립트를 실행한다. 최초 분석은 results 폴더가 이미 있으면 덮어쓰지 않고 실패한다.
check_closed_history.py는 JSON을 표준 출력으로만 반환한다.
