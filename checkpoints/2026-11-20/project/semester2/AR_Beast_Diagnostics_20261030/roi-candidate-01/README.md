# 현재 작업대 분석 영역 후보

저장 사진만 사용한 후보입니다. 실시간 인식이나 Unity에 적용하지 않았습니다.

- 초록 영역: A-D 나사 주변, 임시 18mm 정사각형.
- 하늘색 영역: 네 나사로 정의한 사각형의 중앙 80% 구역.
- 현재 등록된 마커·상자 상대좌표와 높이 60mm를 유지했습니다.
  작업대 전체의 높이·위치 변화는 각 사진의 카메라-작업대 자세 계산으로 반영합니다.
- 각 영역은 렌즈 왜곡을 반영하여 투영하고, 64x64 확인용 이미지로 추출했습니다.
  64x64 변환이 원본 세부 정보를 늘려 주는 것은 아닙니다.

- `image-*/preview.png`: 후보 영역 표시.
- `image-*/screw_a.png`부터 `screw_d.png`, `lid_surface.png`: 확인용 크롭.
- `crop-contact-sheet.png`: 정상 6장의 크롭을 한 장으로 비교.
- `candidate.json`: 후보 치수·좌표·프로필 해시·미적용 상태.
- `image-*/report.json`: 원본 경로·해시·해당 사진의 자세와 투영 결과.

## 검증과 한계

원본 7장과 카메라·작업대 프로필의 해시가 그대로임을 확인했습니다.
후보 도구 테스트 19개를 포함한 관련 테스트 180개가 통과했습니다.
두 테스트를 마지막으로 추가하기 전 전체 테스트도 재실행에서 554개 통과했습니다.
첫 전체 실행에서는 기존 Tk 창 초기화 테스트 1개가 실패했으며, 단독 실행과 전체
재실행에서는 통과했습니다. 최초 실패 결과도 `full-tests.xml`에 남겼습니다.

정상 6장의 전체 사진과 30개 크롭을 육안으로 확인했습니다. 예전 C-D 영역처럼 상자
앞면을 보는 오류는 줄어든 모습이지만, 독립적인 나사 중심 정답을 측정한 것은 아닙니다.
6/7을 정합 정확도나 인식 성공률로 해석하지 않습니다. 영역 크기와 정확한 중심,
돌출된 나사·손 가림은 추가 확인이 필요합니다.

뚜껑 중앙 영역이 맞는 것과 열림/닫힘을 구별하는 것은 별개입니다.
기존 템플릿·임계값은 그대로 옮기지 않습니다. 카메라·Unity 실행, 새 촬영,
외부 전송, 활성 설정 변경은 없었습니다.
