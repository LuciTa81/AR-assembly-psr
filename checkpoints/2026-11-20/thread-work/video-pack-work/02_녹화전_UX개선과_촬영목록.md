# 녹화 전에 바꿀 것과 확보할 장면

## 1. 가장 먼저: 안경 글씨를 줄이기

현재 Unity 코드를 확인하면 단계 제목, 큰 Cue, 행동 설명, 확인 메시지, 진단 힌트가 따로 그려진다. 사용자 입장에서는 여러 줄을 읽어야 하는 구조다.

개선 원칙은 **작은 단계 표시 + 큰 행동 한 줄 + 목표 강조**다. PAUSED, WORKING, MOVE CLEAR 같은 내부 표현은 기본 화면에서 직접 읽게 하지 않는다. 원 위치, 보정, 판단 조건은 그대로 두고 표시 계층부터 분리한다.

| 상황 | 큰 행동 문구 제안 | 보조 표시 |
| --- | --- | --- |
| 상자 배치 | 상자를 놓아주세요 | 몸체 윤곽 |
| 뚜껑 닫기 | 뚜껑을 덮어주세요 | 뚜껑 윤곽 |
| 나사 작업 | 나사 A를 조여주세요 | 작은 A · 1/4, 현재 나사 강조 |
| 작업 관측 중 | 나사 A를 조여주세요 | 기존 파란 강조 유지, 설명 중복 없음 |
| 이탈 안내 | 드라이버를 떼어주세요 | 초록 강조 |
| 작업대 추적 상실 | 작업대가 보이도록 바라봐주세요 | 신뢰할 수 없는 위치 표시는 숨김 |
| 입력 연결 상실 | 멈추고 연결을 확인해주세요 | 작업 중단 필요 상태는 명확히 표시 |
| 최종 검사 | 조립 상태를 확인해주세요 | 전체 윤곽 |
| 최종 확인 후 | 조립 안내를 마쳤습니다 | 윤곽 숨김 |

하나의 'PAUSED' 문장으로 모든 원인을 덮지 않는다. 작업대가 안 보이는 경우와 장치 연결 문제는 행동이 다르다. 잠깐의 상태 변화에는 기존 안정화 로직을 유지해 글씨가 깜빡이지 않게 한다.

한글 글꼴 포함 여부, 한 줄 길이, 좌우 눈의 동일 배치, 큰 글씨가 나사를 가리지 않는지를 확인한다. 보존 상태의 숫자와 원인은 관제의 진단 상세/로그에 남긴다.

완료 기준: 렌더 검사에서 상태별 한 문장, 한글 누락/잘림 없음, 진행 로직과 보정 파일 변경 없음. 이후 짧은 착용 검사로 실제 가독성을 확인한다.

## 2. 상자와 뚜껑 자동 확인은 별도 후보로

현재 성공본에서는 상자/뚜껑과 최종 검사는 사용자 확인이고 A~D는 도구 관측에 따른 자동 진행이다. 자동화를 전제로 이야기를 구성할 수는 있지만, 아직 구현·검증된 사실로 바꾸지는 않는다.

최소 구현 순서:

1. 저장된 상자 없음/있음, 뚜껑 열림/닫힘 자료와 현재 인식 코드를 점검한다.
2. 해당 단계에만 적용하는 확인 조건을 둔다. 짧은 안정 구간의 여러 관측으로 판단하고 손 가림/추적 상실은 완료 증거로 세지 않는다.
3. 상자만 있음과 뚜껑 닫힘을 구분한다. 마커가 보인다는 사실만으로 상자가 놓였다고 판단하지 않는다.
4. 한 번 확정한 단계는 순간 검출 손실로 되돌리지 않는다. 명시적인 작업 재시작은 별도 처리한다.
5. 기존 수동 확인을 유지한 후보 옵션으로 검증한다. 원 좌표와 A~D 작업 흐름은 건드리지 않는다.

오프라인에서 틀린 조기 전이가 없는지 확인한 뒤 실제 열림/닫힘을 비교해야 한다. 자료가 부족하면 그 상태의 촬영이 추가로 필요하다. 자동화를 켜기 전까지 성공본은 보존한다.

## 3. 관제의 운영자 보조

기본 화면을 복잡하게 하지 않도록 '운영자 도구' 안에 다음 단계 확인을 둔다. 현재/다음 단계와 확인 동작을 표시하고, 중복 클릭은 막는다. 서버가 허용한 전이만 수행하며 서버의 상태 검사를 우회하지 않는다.

수동 확인에는 시간, 이전 단계, 다음 단계, 수동 처리라는 구분을 남긴다. 버튼을 접어 둘 수는 있지만 수동 조작을 자동 인식처럼 제시하지 않는다. 최종 검사는 실제 조립 상태를 사용자가 확인하는 절차로 남기는 편이 적절하다.

## 4. 새 녹화 목록

| 우선 | 장면 | 확보할 원본 | 영상에서 쓸 길이 |
| --- | --- | --- | --- |
| 필수 | 몸체→뚜껑→A→B→C→D→최종 확인 | 동일 실행의 Unity 출력과 관제 화면. 원본은 중간을 끊지 않고 확보 | 약 3~4분 |
| 필수 | A 한 사이클 | 접근 전부터 파란 안내, 초록 안내, 드라이버 이탈, B 전환까지 | 실제 동작 길이 그대로 |
| 필수 | 목표 위치 확인 | 같은 착용 상태에서 가까운/원래 거리, 작은 좌우 이동 | 30~50초 |
| 필수 | 관제와 진행 공유 | 작업 영상과 현재 단계가 함께 보이는 화면. 시작/종료 절차 설명은 제외 | 약 35초 |
| 선택 | 짧은 단절 후 복구 | 정상 작업→짧은 관측 끊김→복귀. 실제 결과가 확인된 장면만 | 10~20초 |
| 선택 | 자동 상자/뚜껑 | 자동화가 검증된 뒤 실제 상태 변화와 단계 전환 | 20~40초 |

현실 배경이 필요하면 작업대 카메라와 Unity 출력을 각각 녹화한다. 눈별 투영과 카메라 투영은 다르므로 단순 합성을 실제 안경 시야로 설명하지 않는다. 렌즈를 통한 촬영은 별도 광학 촬영 작업이며 이번 필수 항목이 아니다.

기존 녹화가 15초라고 해서 영상을 반복 재생해 90초로 늘리지 않는다. AI 설명에서는 짧게 재생한 뒤 ArUco/MediaPipe/YOLO 정지 이미지와 처리 도식으로 전환한다.
