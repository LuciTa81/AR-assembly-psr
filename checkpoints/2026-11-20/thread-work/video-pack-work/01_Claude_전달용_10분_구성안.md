# Claude 전달용: AI Assembly Guide 10분 영상용 PPT

## 제작 목표

프로젝트명: **AI Assembly Guide**

부제: **작업 단계 인식 기반 AR 조립 안내**

개발자: 최민준 (C011207), 지도교수: 윤영 교수님

16:9 영상용 PPT를 만든다. 최종 길이는 약 10분, 슬라이드는 12~16장 안팎으로 시작한다. 긴 발표 자료를 그대로 읽는 영상이 아니라, 사진과 실제 Unity 안내 장면이 중심인 제품 시연 영상이다. 새 사용자 실사 촬영 대신 기존 사진을 활용한다.

핵심 메시지: **작업할 위치와 다음 행동을 눈앞에서 확인한다.**

최신 구성 결정: **혼자 시작/종료하는 조작 설명은 영상에서 제외한다.** 기능을 삭제하는 뜻은 아니다. 관제는 작업 영상과 현재 단계가 함께 바뀌는 모습만 약 35초 보여주고, 본편의 비중은 Unity 공간 안내와 실제 작업에 둔다.

AI의 역할은 작업 영상에서 도구를 찾고, 위치와 시간에 따른 관측을 단계 판단에 활용하는 것이다. AR의 역할은 그 결과를 실제 작업 위치에 맞춰 안내하는 것이다. 두 역할을 분리해서 쉽게 설명한다.

## 참고 제안서 활용

`06_참고/AR_교육프로그램_학교용_v8_참고.pptx`는 시각 스타일과 설명 순서를 위한 참고 자료다.

- 도입의 큰 제품 이미지, 분명한 장 구분, 사용 과정을 순서대로 설명하는 방식을 참고한다.
- 이 자료의 교육 상품, 가격, 시장 전망, 회사 소개를 졸업프로젝트 내용으로 옮기지 않는다.
- 한 장에는 한 질문에 대한 답만 둔다. 제목 1개, 핵심 문장 1개, 큰 이미지 또는 영상으로 구성한다.
- 차콜/블랙 바탕, 흰 글자, 청록 강조를 기본으로 한다. 실제 Unity의 파란 작업 중/초록 이탈 안내 색은 바꾸지 않는다.
- 설명 문구는 짧고 담백하게 쓴다. '혁신적인', '획기적인', '완벽한' 등 근거 없는 수식어는 쓰지 않는다.

## 핵심 시연 편집

1. 상자 배치: 몸체 윤곽과 '상자를 놓아주세요'.
2. 뚜껑 닫기: 뚜껑 직육면체 윤곽과 '뚜껑을 덮어주세요'.
3. 나사 A: 뚜껑과 네 나사 중 A만 강조. 접근, 파란 작업 안내, 초록 이탈 안내, B 전환까지 한 사이클은 중간을 자르지 않고 보여준다.
4. 나사 B~D: 각 목표가 바뀌는 순간과 사용자의 동작을 보여주며 반복 설명은 줄인다.
5. 최종 확인: 전체 윤곽, 사용자 확인, 완료 문구.

한글 한 줄 안내는 별도 후보로 준비 중이다. 실제 안경에서 가독성을 확인한 뒤 해당 문구가 보이는 화면을 녹화한다. 기존 영어 성공본의 화면을 한글 후보의 실기 결과로 사용하지 않는다.

상자/뚜껑 자동 확인은 예정된 최종 흐름이다. 녹화 전에 구현·검증되지 않았다면 기존 사용자 확인을 그대로 보여주거나 '상자 배치', '뚜껑 닫기'처럼 중립적으로 설명한다. 수동 조작을 숨겨 자동 인식의 증거로 사용하지 않는다.

## Unity 화면을 보여주는 방법

- 본편은 Unity 출력의 한쪽 눈 화면을 크게 보여주는 방식을 우선한다. SBS 두 화면을 계속 나란히 보여주면 읽기 어렵다.
- 양안 출력 설명 구간에서만 SBS 전체를 2~3초 보여줄 수 있다.
- 검은 배경의 실제 Unity 출력과 작업대 카메라 영상은 나란히 배치해도 좋다. 렌더 화면만으로 현실 배경이 함께 녹화되지는 않는다.
- 카메라와 눈의 시점이 다르므로 Unity 화면을 카메라 위에 단순히 얹어 '정확한 실제 시야'로 설명하지 않는다.
- 원본 작업대 사진 위의 기존 HUD 합성은 도입/설명용으로 사용할 수 있다. 'AR 안내 예시'로 다루며 실제 실시간 캡처와 구분한다.
- PPT 애니메이션으로 만든 안내 전환은 설명 장면이다. 실제 자동 인식 결과로 제시하지 않는다.

## 기술 설명에 적을 사실

실시간 주 흐름:

`카메라 → ArUco 검출/PnP → A~D 위치 계산`

`카메라 → YOLO 도구 검출 → 도구와 목표의 관계 → 시간 증거/FSM → 현재 단계/다음 행동`

`좌표와 단계 → 로컬 HTTP → Unity 양안 안내 + 브라우저 관제`

- 짧은 관측 단절에 대한 진행 보존/재확인과 이탈 증거 복구를 보강했다. 항상 가림을 견딘다고 일반화하지 않는다.
- MediaPipe, HMM/Viterbi는 별도의 오프라인 분석 경로로 설명할 수 있다. 현재 실시간 단계 전이를 HMM이 직접 수행한다고 설명하지 않는다.
- 초록 안내는 실제 체결 토크나 조임 품질의 측정 결과가 아니다. 도구 접근/유지/이탈과 단계 진행에 대한 안내다.
- 이전 문서의 정확도 수치를 현재 실시간 성공률에 붙이지 않는다. 정량 결과를 넣으려면 대상 실험과 지표를 먼저 확인한다.

## TTS와 자막

- TTS는 기본 속도로 짧은 샘플부터 확인한다. 전체를 느리게 늘려 10분을 만들지 않는다.
- 우선 내레이션 7~8분, 동작을 보는 여백/전환 약 2~3분을 배분한다. 최종 길이는 실제 음성 파일로 측정한다.
- '접근했습니다'라고 설명하는 동안 실제 화면에서도 접근 장면이 보이게 맞춘다. 화면과 말이 다른 단계를 가리키지 않게 한다.
- 단계 전환 직전과 직후에는 말을 잠깐 멈춰 변화가 보이게 한다. 전체 영상에 끊임없이 음성을 채우지 않는다.
- 기술 설명은 두세 문장으로 나누고, 도식에서 설명 중인 경로만 강조한다.
- 발음 사전: YOLO=욜로, ArUco=아루코, PnP=피 엔 피, Unity=유니티, VITURE=비처, FSM=에프 에스 엠. 실제 발음은 TTS 샘플로 확인한다.
- 자막은 1~2줄. 안경 안의 안내 글씨를 가리지 않는 위치에 둔다.
- 기존 MP4는 오디오 트랙이 없다. 설명 내레이션과 효과음은 편집 단계에서 별도로 넣는다.

## 장면별 짧은 내레이션 예시

도입: '조립이 익숙하지 않으면 설명서와 부품을 번갈아 확인하게 됩니다. 손을 멈추는 사이, 다음 작업이나 순서를 놓치기도 합니다.'

제품 소개: 'AI Assembly Guide는 작업할 위치와 다음 행동을 AR 안경으로 보여줍니다. 작업자는 눈앞의 안내를 따라가고, 관제 화면에서는 전체 진행을 확인할 수 있습니다.'

나사 시연: '지금 작업할 나사만 밝게 표시됩니다. 드라이버의 위치와 움직임을 관찰해 안내를 바꾸고, 이탈이 확인되면 다음 나사로 이동합니다.'

AI 설명: 'YOLO는 영상에서 드라이버를 찾습니다. 마커로 계산한 나사 위치와 도구 위치를 비교하고, 연속된 관측을 이용해 작업 단계를 판단합니다.'

사용성: '초기 화면에는 상태 설명이 많았습니다. 사용자가 원하는 것은 내부 상태가 아니라, 지금 무엇을 해야 하는지였습니다. 그래서 행동 안내를 우선하는 화면으로 정리합니다.'

마무리: '눈앞에는 다음 작업을, 관제에는 전체 흐름을. AI Assembly Guide는 조립 순서를 따라 작업을 이어가도록 돕습니다.'

위 예시는 톤 기준이며 10분 분량의 완성된 대본은 아니다. 실제 녹화가 확보된 뒤 화면 길이에 맞춰 대본을 확정한다.
