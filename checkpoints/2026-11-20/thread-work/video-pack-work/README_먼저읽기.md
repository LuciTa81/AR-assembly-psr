## 현재 준비 상태

- 기존 자료를 원본 그대로 복사했다. 보정, 실행 파일, 성공본은 변경하지 않았다.
- 최신 몸체/뚜껑/나사 안내의 연속 실행 영상은 아직 이 묶음에 없다. 녹화가 필요한 구간은 구성안에 표시했다.
- AR 사진은 실제 작업대 사진과 Unity로 만든 HUD를 합친 설명용 이미지다. 안경 렌즈를 통해 촬영한 영상은 아니다.
- B 관제 이미지는 저장 상태와 별도 카메라 사진을 사용한 발표용 재생 화면이다. 동기화된 실시간 녹화가 아니다.
- 제공 MP4는 5월의 검출 비교 영상이다. 최신 Unity 시연 영상과 구분해 사용한다.
- 한 줄 한글 안내는 별도 후보로 구현했다. Unity 빌드, 로직 검사, 카메라 없는 화면 검사를 통과했으며 실제 착용 가독성은 아직 확인하지 않았다. 착용 확인 뒤 새 영상에 사용한다. 상자/뚜껑 자동 확인은 별도 후속 과제다.
