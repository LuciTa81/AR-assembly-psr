# take4 동기화와 영상 편집 인계

| 파일 | 용도 |

카메라 단독 편집본은 한 단계 위 `take4/01-camera-trimmed.mp4`에 있다. 기존 `take4/02-unity-sbs-trimmed.mp4`, `take4/03-unity-left-eye-trimmed.mp4`는 이번 시간 보정 전 파일이므로 새 동기화 파일과 구분한다.

## 실제 확인 결과

원본 카메라 21.000초부터 142.500초까지를 사용했다. 원본 Unity는 20.700초부터 동일 길이를 사용했다. 이는 Unity 출력을 카메라에 대해 0.3초 늦추는 정렬이다. 기존 보정 파일, 앱과 PPT는 수정하지 않았다.

카메라의 노란 목표 표시와 Unity 제목이 바뀌는 시점을 각 영상에서 별도로 확인했다.

| 새 단계 | 카메라 원본 시각 | Unity 원본 시각 | 0.3초 정렬 후 잔여 차이 |
| --- | ---: | ---: | ---: |
| A / S2 | 47.900초 | 47.533초 | 약 67ms |
| B / S3 | 70.700초 | 70.367초 | 약 33ms |
| C / S4 | 92.600초 | 92.233초 | 약 67ms |
| D / S5 | 122.000초 | 121.633초 | 약 67ms |
| 최종 확인 / S6 | 140.000초 | 139.700초 | 약 0ms |

카메라는 10fps, Unity는 30fps다. 확인한 다섯 전환에서 잔여 차이는 카메라 한 프레임(100ms) 이내다. 카메라 영상과 상태 HTTP 수신이 별개이므로 모든 프레임의 센서 노출 시각까지 일치한다고 주장할 수는 없다. 제목 전환의 시간 정렬이지 하드웨어 동기화나 정합 정확도 측정은 아니다. B의 새 표시는 70.7초에 처음 나오고 70.8초에 잠깐 사라진다. 그 공백을 편집으로 지우지 않았다.

## 재구성 시험본의 의미

- 원본 카메라 82~96초와 Unity 81.7~95.7초를 사용했다.
- Unity 왼눈의 나사 네 점을 카메라 영상의 네 점에 맞추는 고정 평면 변환을 사용했다.
- Unity의 실제 색과 안내 문구를 사용했다. 화면 상하 안내 문구는 공간 윤곽과 분리해 배치했다.
- 이 변환은 뚜껑 평면에 대한 설명용 재구성이다. 눈 시점, 입체 깊이, 손의 가림, 상자 옆면까지 정확하게 재현하지 않는다.
- 카메라 영상에 원래 포함된 청록 진단선과 노란 목표 표시는 제거하지 않았다. 따라서 원과 선이 겹치고 색이 섞이는 구간이 있다.
- 상단에 `카메라 시점 재구성 · Unity 실제 출력 사용` 표시를 넣었다. 안경 렌즈를 통해 촬영한 장면으로 소개하지 않는다.
- 짧은 추적 단절과 안내 변화는 원본 그대로다. 성공한 것처럼 보이도록 숨김이나 상태 생성은 하지 않았다.

**편집 권장:** 본편에는 동기화 비교본을 쓰고, 양안 원리를 설명할 때 SBS 원본을 짧게 보여준다. 재구성 시험본은 원리 설명용 후보이며 완성된 시연 촬영을 대체하지 않는다.

## 발표 표현과 촬영 조건

이 촬영은 초록 안내 후 약 2초 뒤 다음 단계로 넘어가는 촬영용 옵션을 사용했다. 도구 접근과 단계 안내 시연이지 체결 토크나 기계적 조임 완료를 검증한 영상은 아니다. 클립 마지막은 최종 검사 요청까지이며, 작업자 최종 확인 완료 장면으로 바꾸어 설명하지 않는다.

권장 설명: `작업 위치와 도구 접근을 인식해 현재 나사와 다음 작업을 안내합니다.`

## 다음 편집 순서

1. 기존 PPT 디자인과 구조도를 유지한다.
2. 핵심 시연 페이지에 동기화 비교본을 넣는다. 중복되는 긴 실행 설명은 줄인다.
3. 양안 투영 설명 페이지에는 SBS 원본 10~15초를 넣어 좌우 차이를 보여준다.
4. 실제 시연 내용에 맞춰 내레이션을 정리하고 TTS를 만든다. 작업 동작이 보이는 구간에는 설명을 쉬어간다.
5. 전환과 자막을 맞춘 뒤 약 8~10분으로 전체 영상을 내보낸다. 분량을 맞추려고 TTS만 느리게 늘리지 않는다.
6. 최종 영상의 글씨, 한글 발음, 단계와 화면의 일치, 마지막 프레임과 소리를 확인한다.

측정 세부 자료: `verified-transitions.json`, `verification.json`, `sample-mapping.json`.
