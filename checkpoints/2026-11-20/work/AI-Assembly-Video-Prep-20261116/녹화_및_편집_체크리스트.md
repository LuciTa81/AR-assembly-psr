## 먼저 확보할 장면

### 1. A에서 B까지 이어지는 장면

- 같은 착용 위치와 Full SBS, 0DoF, Extra Large, 4.5m, Windows 확장 설정을 유지한다.
- 상자와 마커 위치를 바꾸지 않는다.
- 상자, 뚜껑 확인 후 A를 진행한다. 아직 B를 작업하지 않는다.
- 주황 안내 → 파란 작업 안내 → 초록 이탈 안내 → 드라이버 이탈 → B로 전환까지 한 번에 기록한다.
- 핵심 장면은 실제 속도로 이어 보여준다. 지연을 편집으로 없애 자동 반응 속도를 과장하지 않는다.
- 영상 저장을 시작하기 전에 저장 위치, 촬영 대상과 사용자 준비를 확인한다. 비밀번호, 알림, 개인 화면은 녹화하지 않는다.

### 2. 전체 조립 안내

- 상자 배치 → 뚜껑 닫기 → A → B → C → D → 최종 확인을 한 번 확보한다.
- 상자, 뚜껑, 최종 확인은 현재 관제에서 직접 확인한다. 이 입력을 자동 인식으로 설명하지 않는다.
- 최초 몸체, 뚜껑 단계의 윤곽과 나사 단계의 목표 강조를 각각 몇 초씩 남긴다.
- 최종 확인 전 전체 윤곽, 확인 후 완료 문구를 확보한다.
- 단순 접근/이탈 검증을 촬영했다면 실제 체결 완료를 검증한 영상이라고 설명하지 않는다. 이미 조인 나사를 추가로 과하게 조이지 않는다.

### 3. 거리와 각도 비교

- 같은 나사 하나를 정면 → 조금 가까이 → 원래 거리 → 약간 측면 → 정면 복귀 순서로 본다.
- 각 자세에서 잠시 멈춰 위치를 비교할 수 있게 한다.
- 서로 다른 날의 사진을 연속적인 추적 시험처럼 연결하지 않는다.
- 짧은 가림 후 복구를 보여주려면 별도 실기에서 실제로 성공한 구간을 사용한다. 그 장면이 없으면 설명만 넣는다.

## 설명에서 지킬 사실

- 실시간: 카메라 입력, ArUco/PnP 위치 계산, YOLO 도구 검출, 시간 조건과 FSM, Unity 안내, 웹 관제.
- 오프라인: 저장 영상의 MediaPipe 특징과 HMM/Viterbi 분석. 현재 실시간 단계를 HMM이 직접 제어한다고 말하지 않는다.
- 근접 유지 조건과 2초 지연 안내는 체결 토크 측정이 아니다. 초록 안내는 도구 이탈 요청이다.
- 상자 배치, 뚜껑 닫기, 최종 확인은 현재 사용자 확인을 포함한다.
- 정량 수치는 평가 데이터와 조건을 확인한 것만 사용한다. 과거 오프라인 정확도를 현재 실시간 조립 성공률로 표기하지 않는다.
