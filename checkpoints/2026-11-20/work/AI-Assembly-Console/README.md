# AI Assembly Guide 관제 실행

1. 바탕화면의 **AI Assembly Guide**를 더블클릭합니다.
2. 안경을 연결하고 Full SBS, 0DoF, Extra Large, 4.5m, Windows 확장 모드를 확인합니다.
3. 관제에서 **연결 확인**을 누릅니다. 이때 카메라는 켜지지 않습니다.
4. 착용 위치와 상자·마커 배치를 확인하고 체크한 뒤 **작업 시작**을 누릅니다.
5. 시작 후 **영상 표시**를 켜 실제 작업대가 보이는지 확인합니다.
6. 상자·뚜껑을 확인하고 A→D 안내에 따라 진행합니다. 마지막에는 직접 완료 확인합니다.
7. 끝나면 **실행 종료**를 누르고 실행 대기 상태로 돌아오는지 확인합니다.

주소: http://127.0.0.1:8764/

## 다시 실행할 때

- 관제 탭의 새로고침이나 탭 닫기는 실행을 종료하지 않습니다.
- 탭을 닫았다면 바탕화면 바로가기로 다시 열고 **실행 종료**를 누릅니다.
- 종료 후 다시 시작하면 상자 배치부터 새 작업을 시작합니다.
- 진행 중인 단계를 지우는 별도 초기화 버튼은 없습니다.
- 완료 화면은 사용자가 실행 종료를 누를 때까지 유지됩니다.
- 안경 화면을 닫으면 해당 실행도 정리됩니다.
- 관제 연결이 끊기면 종료 여부를 확인할 수 없으므로 실제 작업을 멈추고 관제를 다시 엽니다.

## 보존한 것과 기록

기존 성공본과 A–D 보정 파일은 변경하지 않았습니다.
현재 관제는 기존 이탈 복구와 몸체→뚜껑→나사→최종 검사 윤곽을 유지하면서,
한글 행동 안내 v2를 실행합니다. 주황은 `드라이버 끝을 나사 A에 맞춰주세요`,
파랑은 `나사 A를 조여주세요`, 초록은 `드라이버를 떼어주세요`입니다.
초록 안내의 2초 지연은 유지합니다. 짧은 관측 단절에는 문구와 색만 최대 0.75초 보존하며,
무효 좌표의 원은 숨깁니다. 연결 오류나 재확인이 필요하면 복구 안내를 표시합니다.
관제 실행은 A→B 시험의 3분 제한 없이 마지막 확인까지 이어집니다. 종료는 `실행 종료`로 합니다.
카메라 번호는 0으로 고정되어 있으며, 시작 후 실제 작업대 영상을 확인해야 합니다.
사진·영상은 저장하지 않고 숫자 및 실행 로그만 로컬에 남깁니다.

- 관제 로그: 이 폴더의 console.log, console-error.log
- 연결 점검: checks 폴더
- 실행 관리: runs 폴더
- 기존 판단기의 숫자 로그는 기존 세션 저장 위치에 유지됩니다.

## 이번 확인 범위

한글 v2는 짧은 안경 시험에서 A→B 전환이 로그로 확인되었습니다.
관제 연결 변경은 자동 검사 14개와 실행 전 취소 경로로 확인했습니다.
한글 v2의 관제 시작부터 최종 확인까지의 전체 흐름은 직접 확인할 차례입니다.

## 이전 화면으로 되돌리기

관제에서 실행을 종료한 뒤 `profile.json`의 `action_guidance_directory` 항목을 제거하면
기존 영어 성공본을 실행합니다. 성공본, A~D 보정과 이전 한글 실행 파일은 그대로 보존되어 있습니다.
