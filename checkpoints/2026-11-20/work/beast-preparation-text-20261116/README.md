# 상자·뚜껑 안내 문구 안정화 후보

## 범위

2026-11-16. S0(상자 배치), S1(뚜껑 닫기)에서 짧은 추적 단절로 안내 문구가 빈번하게 바뀌는 부분만 수정했다. 기존 S2–S5에 적용하던 표시 보존 규칙을 S0–S1에도 적용하며, 기존 0.75초 예산은 늘리지 않았다.

- `ActionGuidanceDisplay`: 정상 안내를 확보한 동일 세션·동일 단계에서만 일시 보존한다.
- S0–S1의 `NO STAGE TARGET`을 일시 보존 가능한 표시 조건으로 인정한다.
- 시작부터 유효한 안내가 없으면 보존하지 않는다.
- 단계·세션 변경, 연결 해제, 잘못된 입력, 설정 오류, 재확인 요구는 기존대로 처리한다.
- 원·윤곽 좌표, 추적 기준, 단계 전이, 진행 누적, 초록 안내 지연은 변경하지 않았다.
- 문구 보존으로 좌표의 유효 기간이 연장되거나 단계가 넘어가지는 않는다.

0.75초는 마지막으로 사용 가능한 표시를 기준으로 한다. 상위 표시 안정화 계층의 복귀 지연은 기존대로 남아 있으므로, 원본 카메라 프레임의 시각과 동일한 기준은 아니다.
