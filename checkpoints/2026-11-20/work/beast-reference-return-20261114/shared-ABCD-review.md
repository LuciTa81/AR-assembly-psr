# 같은 착용 A~D 저장 좌표 비교, 2026-11-14

## 결론

C와 D를 추가한 공통 양안 모델은 기존 A/B만 사용한 모델보다 제외 자세
예측이 개선됐다. 그러나 실기 검증 전이며 기존 성공본에 적용하지 않았다.
저장점에 맞는 것과 임의 거리/각도에서 실제 나사에 맞는 것은 구분한다.

## 입력 확인

- 동일 setup `20261114-A-mid-near-1652`: A 3자세, B 3자세, C 1자세, D 1자세.
- 사용자가 C/D의 양안 편안함과 착용/화면 설정 유지 여부를 확인했다.
- D frame 1537/1540/1542/1545는 같은 최종 오프셋의 반복 저장이다.
  마지막 1545를 대표로 사용하며 4개의 독립 자세로 세지 않았다.
- 모든 대표 파일의 해시, 프로필, 양안 짝, 관측 나이, 화면 범위를 검사했다.
- 저장 마커 모서리로 PnP를 재계산하여 XYZ를 재현했다. 각 수집 당시 후보와
  오프셋으로 final 픽셀을 재현했다. 서로 다른 후보의 상대 오프셋은 섞지 않았다.
- 202mm 후보가 아닌 현재 수집에 사용된 기존 작업대 프로필을 유지했다.

## 비교 결과

단위는 눈별 화면 픽셀 오차다. 실제 나사와의 mm 오차나 실물 정확도는 아니다.

| 계산 | RMS | 최대 |
| --- | ---: | ---: |
| 기존 A/B 6자세 모델, 저장점 적합 | 5.66 | 11.09 |
| A~D 8자세 모델, 저장점 적합 | 5.57 | 9.62 |
| 기존 A/B, 한 자세씩 제외한 내부 검사 | 26.47 | 52.37 |

두 제외 검사 집합은 6개/8개로 다르다. 동일한 A/B 6자세만 비교해도
최대 오차는 52.37 -> 27.79px로 줄었다. 새 수집 자료까지 이용해 재적합한
내부 진단이지, 새 독립 착용 실험의 성능 개선 수치가 아니다.

원래 A/B 모델을 고정한 상태에서 새 C/D를 예측한 결과는 별도로 보존했다:
C 32.70/36.74px, D 34.27/21.45px. 재적합으로 이 결과를 덮어쓰지 않는다.

## 해석과 다음 확인

- 수집은 유용했다. 세로 시야 범위가 넓어지고 B와 D 예측이 개선됐다.
- C/D는 각각 한 자세뿐이다. 특히 C와 A 중간은 제외 검사에서 오차가 남아
  가까운/먼 거리와 측면까지 정합됐다고 선언할 수 없다.
- PD 64mm는 참고값이다. 적합된 유효 간격 77.72mm는 실제 사용자 PD 측정이 아니다.
- 다음은 기존 성공본과 분리한 새 후보의 자동 표시 검증이다. 먼저 A와 C를
  조절 없이 편한 정면 자세에서 확인하고, 작은 거리 변화 후 원래 자세로
  돌아오는 비교를 한다. 정확한 머리 좌표를 요구하지 않는다.
- 사용자가 다시 준비됐다고 확인하기 전에는 카메라/Unity를 실행하지 않는다.
  보정 수집을 무작정 반복하거나 기존 C/D 보정을 덮어쓰지 않는다.
