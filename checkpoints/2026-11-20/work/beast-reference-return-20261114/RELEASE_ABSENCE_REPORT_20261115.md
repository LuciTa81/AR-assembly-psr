# 이탈 후 미검출 후보 검증

## 결론
기본값을 끈 후보 옵션을 추가했다. 기존 실행 설정, Unity 실행 파일과 A-D 보정은 바꾸지 않았다. 카메라, Unity를 실행하거나 새 사진, 영상을 저장하지 않았다.

정상 영상에서 드라이버가 사라졌다는 이유만으로 단계가 넘어가지는 않는다. **근접 유지가 이미 확인되었고, 도구 끝이 모든 나사에서 떨어진 유효 관측이 먼저 있어야 한다.**

## 적용 조건
1. 기존 HOLD 조건을 충족한 상태.
2. 현재 및 원본 관측의 마커 유효성, 관측 식별자/시간 검사를 통과.
3. 유효한 단일 도구 관측에서 모든 나사 근접 점수가 release_score_max 이하.
4. 그 직후 max_gap_ms(현재 350ms) 이내의 새 분석 결과에서 영상 전체 드라이버와 손잡이가 모두 미검출.
5. 새 원본 관측 시각 기준으로 미검출이 후보값 600ms 동안 연속 확인되면 한 단계만 전환.

기존 driver_count는 작업 영역으로 제한된 개수이므로 이것만으로는 미검출을 인정하지 않는다. driver_count_raw=0, handle_count=0, handle_visible=0 등 전체 영상의 검출 결과도 확인한다. 검출 실패, 준비 중, 오래된 결과는 evidence_valid 검사를 통과하지 못한다.

동일 관측의 재사용으로 시간이 늘어나지 않는다. 카메라 프레임 공백, 관측 공백, 마커 단절, 도구 재등장, 잘못된 숫자, 도구 위치 불명확은 미검출 확인을 취소한다. 새 clear 관측 없이는 미검출만으로 재개할 수 없다. 기존 HOLD 진행 보존 규칙은 유지한다. 미검출 확인 중 도구가 다시 보이면 기존 이탈 시간 역시 새 visible 관측부터 다시 계산한다.

재등장 및 프레임 공백에서는 마지막 실제 clear 시각을 기준으로 기존 HOLD 복구 조건과 기한을 다시 적용한다. 중립 위치나 다른 나사 위에 재등장했다고 완료 HOLD의 기한을 늘리거나 이전 나사를 완료하지 않는다.

## 설정
`state_filter.timing.release_absence_ms`: 기본 0(비활성), 허용 0 또는 400..1000 정수, 검증 후보 600.

활성 YAML과 실행 스크립트에는 추가하지 않았다. 다음 실기에서만 별도 후보 실행 설정으로 600을 전달할 수 있다. 기존 retain_neutral_recovery 옵션과 독립적이다.

## 검증
- 변경 전: 기존 이탈 후 미검출 시나리오가 S2에 남아 새 기대값 S3를 충족하지 못함을 확인.
- 신규 테스트 63개: A-D 각 단계, 입력 주기 100/200/300ms, 갑작스러운 가림, 근접 미완료, 손잡이만 보임, 작업 영역 밖 드라이버, 입력 누락/오류, 마커 단절, 중복/오래된 관측, 재접근, 명시적 초기화, 다음 단계 증거 누출 방지, 실제 검출 결과 유효성 경로, 재등장과 프레임 공백에서 기존 HOLD 기한 유지.
- 최종 전체 공식 tests: 935 passed (66.33s). `release-absence-tests-reviewed.xml`.
- 기존 보정/성공본 보호 파일: 9개 해시 일치.
- 저장 세션 5개: 8,405프레임 모두 기존 결과와 정확히 재생됨. 후보 ON/OFF의 상태, 안내, 전환 결과도 같음.

위 로그에는 전체 미검출 결과는 있지만, 완료 HOLD + 직전 clear + 정상 연속 미검출 조합이 없었다. **실제 이탈 지연이 개선되었다고 볼 근거는 아직 없다.** 마지막 D 시험에서 보였던 애매한 거리 점수로 인한 release 초기화를 고치는 변경도 아니다.

최종 로그 비교 파일: `release-absence-replay-reviewed.json`.

## 별도 검토 반영
- 미검출 뒤 다른 나사에 재등장하면 이전 HOLD로 잘못 전환할 수 있는 사례를 재현해 수정했다.
- 중립 재등장으로 원래 HOLD 보존 기한이 연장되는 사례를 재현해 수정했다.
- 프레임 간격 초과가 재등장 검사보다 먼저 이력을 지워 복구 규칙을 우회하는 사례도 회귀 테스트로 고정했다.
- 재검토에서 마지막 clear 1900ms, 원래 만료 시각 3900ms가 유지되고, 4000ms 이후 clear가 이어져도 오진행하지 않음을 확인했다. 해당 경계 조건의 추가 차단 사항은 없었다.

## 다음 실기
착용 및 보정 유지, D만 짧게 실행한다. 먼저 정상 안내에 맞춰 도구를 D에서 떼고, 나사들에서 떨어진 위치가 카메라에 잠깐 보이게 한 다음 화면 밖으로 뺀다. 최종 확인으로 전환되는지와 로그의 새 미검출 경로 진입 여부를 함께 확인한다.

실제 나사 조임 강도나 토크를 판정하지 않는다. 잘못된 clear 위치 추정 뒤 연속 미검출이 생기는 경우는 숫자 규칙만으로 물리 이탈과 완전히 구별할 수 없으므로, 실기 검증 전에는 성공본에 적용하지 않는다.
