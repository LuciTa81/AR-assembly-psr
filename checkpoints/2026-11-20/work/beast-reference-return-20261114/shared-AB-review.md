# A/B 공통 양안 모델 오프라인 검토

## 결론

정확한 머리 위치를 사용자에게 요구할 필요는 없다. 편한 자세에서 조절한
최종 좌우 화면 좌표와 그 화면에 사용한 카메라 XYZ를 짝으로 사용한다.
다만 비슷한 위치의 반복 저장이 아니라, 관측 범위를 넓히는 자료와 별도
검증 자료가 필요하다. 이번 결과는 아직 새 보정을 활성화할 근거가 아니다.

## 입력 확인

- 같은 착용 조건으로 확인한 `20261114-A-mid-near-1652`의 A 3개, B 3개 자세.
- 마지막으로 선택한 중간 자세와, 사용자가 모두 편했다고 확인한 가까운 두
  자세를 대상별로 유지했다. 반복 저장을 별도 자세로 세거나 불리한 점을 빼지 않았다.
- A와 B는 표시 후보가 다르므로 후보에 대한 조절량을 섞지 않았다.
  각각 `base + offset = final`을 재현한 뒤 절대적인 눈별 `final` 좌표를 사용했다.
- 후보/프로필 해시, 동일 착용 식별자, 양안 확인, 출력 크기/좌표계, 관측 나이를
  검사했다. 원본 마커 모서리에서 PnP를 다시 계산해 여섯 XYZ를 재현했다.
- 이 확인은 데이터 내부 일관성 검사다. 실제 눈에서의 오차나 착용 불변을
  독립적으로 측정했다는 뜻이 아니다.

## 기존 공통 모델 재사용

`server/realtime/display_joint_fit.py`의 13변수 양안 모델을 그대로 사용했다.
공통 회전과 초점거리, 눈별 화면 중심, 수평 양안 간격을 적합하며 PD 64mm는
참고값으로 사용한다. 새 런타임 투영 방식이나 눈별 DLT를 추가하지 않았다.

| 계산에서 제외한 자세 | 왼눈 예측 오차 | 오른눈 예측 오차 |
| --- | ---: | ---: |
| A 중간 | 22.45 px | 22.52 px |
| A 가까운 1 | 12.85 px | 19.14 px |
| A 가까운 2 | 9.70 px | 13.31 px |
| B 중간 | 52.37 px | 41.02 px |
| B 가까운 1 | 36.21 px | 16.85 px |
| B 가까운 2 | 18.72 px | 15.00 px |

여섯 점을 모두 넣은 적합에서는 RMS 5.66px, 최대 11.09px다. 그러나 위처럼
다섯 자세로 남은 하나를 예측하면 최대 52.37px다. 표의 수치는 저장 화면
좌표와 계산의 차이이며, 나사에서의 mm 오차나 새 실기 정확도가 아니다.
이 검사는 내부 교차검증이며 별도 검증 촬영을 대신하지 않는다.

PD 참고값의 가중치를 바꾸면 모델의 유효 양안 간격은 약 70.98~80.38mm로
달라진다. 이를 사용자의 실제 PD로 해석하거나 64mm 측정이 틀렸다고 판단하면
안 된다. 관측 잡음, 기하 오차, 단순화한 투영 가정 등을 함께 검토해야 한다.

## 관측 범위

- A/B 여섯 점의 카메라 정규화 세로 좌표 `Y/Z`: 0.0418~0.1302.
- 같은 여섯 자세에서 계산한 C/D 12개 위치의 `Y/Z`: 0.2746~0.4004.
- 따라서 이 자료만으로 C/D를 맞췄다고 할 수 없다. 그림의 빈 C/D 표시는
  계산된 목표 위치일 뿐 사용자 보정 관측이 아니며 적합에 넣지 않았다.
- XYZ 자체는 완전히 평면으로 퇴화하지 않았지만, Y와 Z 상관은 약 0.842로
  높다. 거리와 세로 시점이 함께 변해 각 영향을 분리하기 어렵다.
- 원인 단정은 하지 않는다. 여섯 점은 수학적 적합이 가능하다는 뜻이지
  충분한 데이터나 올바른 광학 모델임을 보장하지 않는다.

## 다음 최소 수집

1. 같은 착용을 유지했는지 먼저 확인한다. 벗거나 조절했다면 새 세트로 구분한다.
2. C, D를 각각 편한 중간 자세에서 한 번씩 맞춘다. 정확한 cm/각도는 요구하지
   않고 실제 저장된 XYZ와 화면 방향 범위로 새 정보가 추가됐는지 판단한다.
3. 범위가 여전히 겹치면 고개를 편한 범위에서 조금만 달리한 관측을 1~2개
   추가한다. 무작위 반복이나 같은 자세 Enter 반복으로 표본 수를 늘리지 않는다.
4. 새 관측은 별도 실험 세트에만 추가하고, 기존 성공본의 C/D 보정은 유지한다.
   공통 적합과 제외-예측 검사를 다시 통과해야 자동 표시 후보를 만든다.
5. 후보가 나오면 보정에 쓰지 않은 편한 자세에서 먼저 조절 없이 확인한다.
   처음/끝 기준 자세도 비교한다. 개선되지 않으면 수집을 계속 요구하지 않고
   카메라 목표 등록/추적/눈 투영을 나눠 원인을 조사한다.
