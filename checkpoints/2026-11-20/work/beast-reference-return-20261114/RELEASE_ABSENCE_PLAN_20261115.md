# 이탈 후 미검출 후보

## 범위와 결정
- 기존 성공본, A-D 보정, 활성 설정, Unity 화면은 유지한다. 카메라를 켜지 않는다.
- 단순 미검출은 이탈로 취급하지 않는다. 완료 HOLD 이후 모든 나사에서 떨어진 유효 도구 좌표를 먼저 요구한다.
- 그 직후 정상적인 새 검출 결과에서 영상 전체 드라이버와 손잡이가 모두 없을 때만 보조 이탈 확인을 시작한다.
- `GuidanceTiming.release_absence_ms`: 기본 0(비활성), 후보 600ms. 허용값은 0 또는 400..1000ms.
- 시간은 새 관측의 원본 시각으로 계산한다. 중복 결과는 시간을 추가하지 않는다.
- 첫 미검출은 마지막 clear 관측에서 `max_gap_ms` 안이어야 한다. 이후 연속 미검출과 정상 마커를 요구하며, 전체 후보 수명은 clear + max_gap + release_absence로 제한한다.
- 마커/입력/검출 오류, 간격 초과, 도구 재등장, 애매한 위치, 다른 나사 접근은 미검출 확인을 취소한다. 기존 HOLD 보존 규칙은 그대로 적용한다.
- 물리적 체결이나 토크 확인이 아니며, 실기 효과는 별도 검증해야 한다.

## 완료 조건
검출 누락만으로는 진행하지 않고, 이전 clear + 연속된 유효 미검출에서만 한 단계 진행한다. 다음 단계로 증거가 넘어가지 않는다. 옵션 OFF의 기존 로그 재생 결과는 일치한다. 기본 설정을 켜거나 실기 성공을 주장하지 않는다.
