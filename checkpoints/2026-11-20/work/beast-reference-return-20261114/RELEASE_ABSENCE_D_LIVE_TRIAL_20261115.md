# D 미검출 이탈 후보 실기: 개선 효과 미확인

## 실행 및 사용자 결과
- 세션: `viture_aruco_rt_20261115_012657_a830efa91f0b`.
- D(S5)에서 최종 확인(S6)까지만, 최대 90초. 숫자 로그 867프레임, 86.619초.
- 기존 A-D 공통 보정, Unity 시험 빌드, 접근 800ms, 이탈 400ms, HOLD 보존 600/2000ms, 초록 안내 지연 2000ms 유지.
- 직전 D 시험 설정과 다른 항목은 `release_absence_ms=600` 및 독립 로그 폴더뿐임을 실행 전에 비교했다. 기존 `retain_neutral_recovery=true`도 유지했다.
- 사용자는 최종 확인 문구에 대해 **"안나왔어"**라고 답했다. 화면 밖 이탈 시점과 정확한 재등장 동작은 확인되지 않았다.
- 카메라/Unity 및 관련 소유 프로세스 종료 확인. 사진/영상 저장 파일 없음. 보호된 성공본/보정 파일 9개 해시 일치.

## 동일 입력 ON/OFF 비교
실제 저장 입력을 현재 코드로 정확히 재생했다. OFF는 새 옵션만 0으로 바꾸고 나머지는 유지했다.

| 항목 | 결과 |
|---|---|
| 정확한 실기 로그 재생 | 867프레임 일치 |
| ON/OFF 출력 차이 | 201, 202, 203 프레임 |
| 새 미검출 경로 | 고유 원본 관측 1개 |
| 새 미검출 경로에 의한 전환 | 없음 |
| D -> S6 | ON/OFF 모두 834프레임 |
| 전체 영상 미검출과 유효 입력 동시 충족 | 프레임 행 42개, 중복 관측 포함 |

새 옵션으로 이탈이 빨라졌다고 볼 근거는 없다. 834프레임의 전환은 기존의 도구가 보이는 상태에서의 이탈 확인이다. 고정 로그 비교는 실제 동작을 바꾸지 않으므로 체감 지연 감소의 측정값이 아니다.

## 새 조건이 취소된 이유
1. 200프레임에서 원본 관측 198의 도구 위치가 모든 나사에서 충분히 떨어진 것으로 판정됐다.
2. 201프레임에서 원본 관측 200의 드라이버/손잡이 전체 미검출이 들어와 새 경로가 시작됐다.
3. 202, 203프레임은 같은 원본 관측의 재사용이므로 미검출 유지 시간이 늘지 않았다.
4. 204프레임에서 원본 관측 202의 `handle_count=1`, `handle_visible=1`이 들어와 미검출 확인을 취소했다. 그때 마커와 분석 결과는 유효했다.
5. 후속 관측에서도 손잡이 또는 드라이버 검출이 이어졌고, 219프레임에서 완료 HOLD 보존 기한이 만료됐다.

실제 손잡이가 남아 있었는지 오검출인지 숫자만으로 단정할 수 없다. 사진/영상은 저장하지 않았다. 따라서 미검출 시간을 줄이거나 손잡이 검출을 무시하는 변경은 하지 않는다.

## 최종 확인 문구를 놓치기 쉬운 표시 흐름
| 프레임 | 서버 상태 | 첫 입력 기준 시각 |
|---|---|---|
| 834-835 | S6 / AWAITING_CONFIRMATION | 83.322-83.420초 |
| 836-859 | S6 / PAUSED | 83.531-85.820초 |
| 860-867 | S6 / AWAITING_CONFIRMATION | 85.931-86.619초 |

S6 진입 209ms 뒤 마커 자세가 무효가 되면서 PAUSED로 덮였다. 약 2.4초 뒤 복구됐지만 시험 종료 직전이었다. 단계 자체는 S6에 유지됐고 D로 돌아간 것은 아니다.

Unity 로그에도 `FINAL CHECK -> PAUSED -> FINAL CHECK` 순서가 있다. 이는 앱의 문구 선택 기록이지 사용자가 실제로 충분히 읽었다는 증거는 아니다. 사용자 응답을 우선해 화면 확인 성공으로 판정하지 않는다. 이 시험은 최종 작업자 확인을 자동 수행하지 않는다.

## 다음 작업
1. 후보 옵션은 기본 OFF 유지. 기존 성공본에 승격하지 않는다.
2. S6에 도달한 뒤에는 공간 원을 숨기더라도 최종 확인 문구가 마커 단절에 덮이지 않도록 하는 변경을 별도 후보로 검토한다. 최종 확인은 계속 사용자 입력이며 자동 완료로 바꾸지 않는다.
3. 이탈 증거 개선은 마지막 유효 도구 위치, 부분 손잡이 검출, 확인된 미검출을 구분한 저장 입력부터 재현한다. 손잡이 오검출 여부가 필요한 시점에만 사용자 동의를 받아 짧은 진단 촬영을 고려한다.
4. 동일 조건 재시험을 즉시 반복하거나 임계값을 일괄 완화하지 않는다. A-D 정합 보정은 이 문제의 수정 대상이 아니다.
