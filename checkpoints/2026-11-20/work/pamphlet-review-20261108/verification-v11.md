# AR 안내 이미지 v11 검증

## 결과
- `ar-guidance-B-photo-unity-v11.png`: 1530 x 1020 최종 미리보기.
- `ar-guidance-B-photo-unity-v11-half.png`: 765 x 510 검토본.
- `ar-guidance-B-photo-unity-v11-small.png`: 306 x 204 가독성 확인본.

## 보존
- 기존 실제 사진의 크롭과 비례 확대를 그대로 사용했다.
- 상자, 마커, 매트, 원근, 조명, 배경을 재생성하지 않았다.
- 원본 SHA-256이 v10 기록과 일치한다.
- 오버레이 밖 1,534,954개 픽셀은 사진과 정확하게 동일하다.
- 기존 성공 앱, A-D 보정, 실시간 서버, Google Slides는 변경하지 않았다.
- 카메라 및 안경 출력은 실행하지 않았다.

## 안내 그래픽
- 별도 Unity 6000.3.25f1 프로젝트의 orthographic camera와 RenderTexture로 렌더했다.
- 뚜껑 외곽의 낮은 대비 선, 모서리 강조, B 원과 짧은 아래 방향 화살표를 추가했다.
- Noto Sans KR의 실제 weight 600 인스턴스로 한글을 렌더했다.
- 문구: `나사 B · 2/4`, `나사 B를 조여주세요.`
- 검정/흰색 배경 렌더로 투명도를 복원했으며 채널별 최대 차이는 2/255였다.
- Unity 빌드와 렌더 실행은 exit 0, 이미지 검사 통과.
- 최종본 및 306 x 204 축소본을 육안 확인했다. 주 안내는 읽히며, 상단 단계 표기는 보조 정보로 작게 보인다.

## 표현 구분
실제 작업대 사진 위에 Unity에서 렌더한 새 안내 디자인을 배치한 미리보기다.
테두리와 화살표 좌표는 이 사진에 맞춘 편집 좌표이며, 새 실시간 정합 기능이나 안경 렌즈를 통과해 촬영한 화면의 검증을 의미하지 않는다.

## 재현
1. 별도 Unity 프로젝트 `unity-overlay-v11`에서 `PreviewBuilder.Build` 실행.
2. 생성된 `unity-overlay-player-v11/Preview.exe`에 `--output`으로 `unity-overlay-capture-v11` 지정.
3. `build-real-overlay-v11.cjs` 실행. 원본 해시, 렌더 크기, 빈 화면, matte 일치, 오버레이 면적, 사진 보존 검사 포함.

초기 숨김 창 화면 캡처는 빈 화면이어서 사용하지 않았다. 최종본은 창 표시 상태와 무관한 오프스크린 렌더를 사용한다.
